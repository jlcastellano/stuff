1. Sistema Básico de Registro de Gastos

Desarrolle una aplicación de escritorio simple en Java para registrar y visualizar gastos personales. La aplicación debe permitir el registro básico de gastos y su categorización mediante una interfaz gráfica intuitiva.

Requisitos Funcionales

  • Implementación de la estructura de datos (25 puntos)
    • Utilizar HashMap para almacenar gastos por categoría
    • Crear clases necesarias para representar gastos y categorías
  • Interfaz gráfica con Swing (40 puntos)
    • Ventana principal con menú de opciones
    • Formulario para añadir nuevos gastos
    • Panel para mostrar lista de gastos
    • Vista de resumen simple por categorías
  • Gestión de datos (35 puntos)
    • Guardar gastos en archivo de texto plano o binario
    • Cargar datos al iniciar la aplicación
    • Validación básica de entrada de datos

Funcionalidades Mínimas Requeridas

  • Agregar un nuevo gasto (cantidad, categoría, fecha)
  • Visualizar lista de gastos registrados
  • Mostrar suma total por categoría
  • Guardar datos de forma persistente
  • Cargar datos guardados previamente

Criterios de Evaluación

• Funcionalidad básica completa (40%)
• Interfaz gráfica funcional y usable (25%)
• Manejo de errores básicos (15%)
• Estructura y organización del código (15%)
• Comentarios y documentación básica (5%)

2. Sistema de Control de Asistencia para Pequeño Negocio

Desarrolle una aplicación de escritorio en Java para gestionar el control de asistencia de empleados en un pequeño negocio. El sistema debe permitir registrar entradas y salidas, calcular horas trabajadas y generar reportes básicos.

Requisitos Funcionales

  • Gestión de empleados (20 puntos)
    • Alta y baja de empleados
    • Asignación de identificadores únicos
    • Almacenamiento de datos básicos
  • Sistema de fichaje (30 puntos)
    • Registro de entrada/salida
    • Validación de empleado
    • Captura automática de hora
  • Cálculos y reportes (30 puntos)
    • Cálculo de horas trabajadas
    • Generación de reportes por empleado
    • Resumen mensual en formato texto
  • Interfaz gráfica (20 puntos)
    • Panel de fichaje
    • Vista de histórico
    • Gestión de empleados

Funcionalidades Mínimas

  • Registro de empleados (nombre, ID, departamento)
  • Sistema de fichaje básico (entrada/salida)
  • Cálculo automático de horas trabajadas por día
  • Visualización del histórico de fichajes
  • Generación de informe básico de asistencia
  • Persistencia de datos entre ejecuciones
  • Validación de fichajes (evitar múltiples entradas/salidas)

Criterios de Evaluación

• Implementación del sistema de fichaje (35%)
• Precisión en cálculos de tiempo (25%)
• Interfaz de usuario (20%)
• Gestión de datos (15%)
• Documentación (5%)

3. Gestor de Recetas de Cocina

Desarrolle una aplicación para gestionar y organizar recetas de cocina. El sistema debe permitir almacenar, buscar y visualizar recetas, incluyendo ingredientes y pasos de preparación.

Requisitos Funcionales

  • Estructura de datos (25 puntos)
    • Implementación con TreeMap para categorización
    • Modelo de datos para recetas e ingredientes
    • Sistema de categorías jerárquico
  • Gestión de recetas (35 puntos)
    • Alta y modificación de recetas
    • Gestión de ingredientes y cantidades
    • Almacenamiento en archivo binario
  • Sistema de búsqueda (20 puntos)
    • Búsqueda por nombre
    • Filtrado por ingredientes
    • Búsqueda por categoría
  • Interfaz de usuario (20 puntos)
    • Formulario de ingreso de recetas
    • Visualización de recetas
    • Panel de búsqueda

Funcionalidades Mínimas

  • Agregar nueva receta con ingredientes y pasos
  • Buscar recetas por nombre o ingredientes
  • Categorizar recetas
  • Guardar y cargar recetas desde archivo
  • Visualizar recetas completas

Criterios de Evaluación

• Implementación del TreeMap y estructura de datos (30%)
• Sistema de búsqueda y filtrado (25%)
• Interfaz gráfica y usabilidad (25%)
• Persistencia de datos (15%)
• Documentación (5%)
