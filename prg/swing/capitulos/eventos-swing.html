Eventos en Swing

1. ActionListener

Para eventos de acción simple como clics en botones o selección de menús.

JButton button = new JButton("Clic");
button.addActionListener(new ActionListener() {
    @Override
    public void actionPerformed(ActionEvent e) {
        System.out.println("Botón presionado");
    }
});

// Usando lambda
button.addActionListener(e -> System.out.println("Botón presionado"));

Componentes que lo utilizan:

  • JButton
  • JMenuItem
  • JTextField
  • JComboBox

2. MouseListener

Para eventos relacionados con el ratón.

component.addMouseListener(new MouseAdapter() {
    @Override
    public void mouseClicked(MouseEvent e) {
        System.out.println("Clic en: " + e.getX() + "," + e.getY());
    }
    
    @Override
    public void mouseEntered(MouseEvent e) {
        System.out.println("Ratón entró");
    }
    
    @Override
    public void mouseExited(MouseEvent e) {
        System.out.println("Ratón salió");
    }
});

Eventos disponibles:

  • mouseClicked
  • mousePressed
  • mouseReleased
  • mouseEntered
  • mouseExited

3. KeyListener

Para eventos de teclado.

textField.addKeyListener(new KeyAdapter() {
    @Override
    public void keyPressed(KeyEvent e) {
        if (e.getKeyCode() == KeyEvent.VK_ENTER) {
            System.out.println("Enter presionado");
        }
    }
    
    @Override
    public void keyTyped(KeyEvent e) {
        char c = e.getKeyChar();
        if (!Character.isDigit(c)) {
            e.consume(); // Ignora caracteres no numéricos
        }
    }
});

Eventos disponibles:

  • keyPressed
  • keyReleased
  • keyTyped

4. ItemListener

Para componentes que pueden cambiar su estado de selección.

JCheckBox checkBox = new JCheckBox("Opción");
checkBox.addItemListener(new ItemListener() {
    @Override
    public void itemStateChanged(ItemEvent e) {
        boolean selected = (e.getStateChange() == ItemEvent.SELECTED);
        System.out.println("Seleccionado: " + selected);
    }
});

Componentes que lo utilizan:

  • JCheckBox
  • JRadioButton
  • JComboBox
  • JToggleButton

5. DocumentListener

Para monitorear cambios en componentes de texto.

JTextField textField = new JTextField();
textField.getDocument().addDocumentListener(new DocumentListener() {
    @Override
    public void insertUpdate(DocumentEvent e) {
        updateText();
    }
    
    @Override
    public void removeUpdate(DocumentEvent e) {
        updateText();
    }
    
    @Override
    public void changedUpdate(DocumentEvent e) {
        updateText();
    }
    
    private void updateText() {
        System.out.println("Texto actual: " + textField.getText());
    }
});

Componentes que lo utilizan:

  • JTextField
  • JTextArea
  • JEditorPane
  • JTextPane

6. WindowListener

Para eventos relacionados con la ventana.

frame.addWindowListener(new WindowAdapter() {
    @Override
    public void windowClosing(WindowEvent e) {
        System.out.println("Ventana cerrándose");
    }
    
    @Override
    public void windowActivated(WindowEvent e) {
        System.out.println("Ventana activada");
    }
});

Eventos disponibles:

  • windowOpened
  • windowClosing
  • windowClosed
  • windowIconified
  • windowDeiconified
  • windowActivated
  • windowDeactivated

7. ListSelectionListener

Para eventos de selección en listas y tablas.

JList list = new JList<>(new String[]{"Item 1", "Item 2"});
list.addListSelectionListener(new ListSelectionListener() {
    @Override
    public void valueChanged(ListSelectionEvent e) {
        if (!e.getValueIsAdjusting()) {
            System.out.println("Selección: " + list.getSelectedValue());
        }
    }
});

Componentes que lo utilizan:

  • JList
  • JTable

8. FocusListener

Para eventos de foco en componentes.

component.addFocusListener(new FocusAdapter() {
    @Override
    public void focusGained(FocusEvent e) {
        System.out.println("Componente ganó el foco");
    }
    
    @Override
    public void focusLost(FocusEvent e) {
        System.out.println("Componente perdió el foco");
    }
});

Ejemplo Completo de Manejo de Eventos

public class EjemploEventos extends JFrame {
    public EjemploEventos() {
        setTitle("Demo de Eventos");
        setLayout(new FlowLayout());
        
        JTextField textField = new JTextField(20);
        JButton button = new JButton("Enviar");
        JLabel label = new JLabel("Resultado: ");
        
        // ActionListener para el botón
        button.addActionListener(e -> {
            label.setText("Resultado: " + textField.getText());
        });
        
        // KeyListener para el campo de texto
        textField.addKeyListener(new KeyAdapter() {
            @Override
            public void keyPressed(KeyEvent e) {
                if (e.getKeyCode() == KeyEvent.VK_ENTER) {
                    button.doClick();
                }
            }
        });
        
        // DocumentListener para el campo de texto
        textField.getDocument().addDocumentListener(new DocumentListener() {
            public void changedUpdate(DocumentEvent e) { updateLabel(); }
            public void removeUpdate(DocumentEvent e) { updateLabel(); }
            public void insertUpdate(DocumentEvent e) { updateLabel(); }
            
            private void updateLabel() {
                label.setText("Escribiendo: " + textField.getText());
            }
        });
        
        add(textField);
        add(button);
        add(label);
        
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        pack();
        setLocationRelativeTo(null);
    }
    
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            new EjemploEventos().setVisible(true);
        });
    }
}

Mejores Prácticas

  • Usar clases Adapter cuando no se necesiten todos los métodos del listener
  • Evitar operaciones largas en los manejadores de eventos
  • Mantener el código de los listeners organizado y modular
  • Remover los listeners cuando ya no sean necesarios
  • Validar los eventos antes de procesarlos
