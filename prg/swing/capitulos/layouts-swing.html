Gestores de Layout en Swing

1. FlowLayout

Organiza los componentes en una línea, creando nuevas líneas cuando es necesario.

JPanel panel = new JPanel(new FlowLayout());
// FlowLayout.LEFT, FlowLayout.CENTER, FlowLayout.RIGHT
panel.setLayout(new FlowLayout(FlowLayout.LEFT, 10, 10)); // hgap=10, vgap=10
panel.add(new JButton("Botón 1"));
panel.add(new JButton("Botón 2"));
panel.add(new JButton("Botón 3"));
                [Botón 1] [Botón 2] [Botón 3]
                // Si no hay espacio:
                [Botón 1] [Botón 2]
                [Botón 3]

2. BorderLayout

Divide el contenedor en cinco áreas: Norte, Sur, Este, Oeste y Centro.

JFrame frame = new JFrame();
frame.setLayout(new BorderLayout(5, 5)); // hgap=5, vgap=5
frame.add(new JButton("Norte"), BorderLayout.NORTH);
frame.add(new JButton("Sur"), BorderLayout.SOUTH);
frame.add(new JButton("Este"), BorderLayout.EAST);
frame.add(new JButton("Oeste"), BorderLayout.WEST);
frame.add(new JButton("Centro"), BorderLayout.CENTER);
                     [    Norte    ]
                [Oeste][Centro][Este]
                     [    Sur     ]

3. GridLayout

Organiza los componentes en una cuadrícula de filas y columnas del mismo tamaño.

JPanel panel = new JPanel(new GridLayout(2, 3, 5, 5)); // 2 filas, 3 columnas, hgap=5, vgap=5
for (int i = 1; i <= 6; i++) {
    panel.add(new JButton("Botón " + i));
}
                [Botón 1][Botón 2][Botón 3]
                [Botón 4][Botón 5][Botón 6]

4. GridBagLayout

El layout más flexible pero complejo. Permite control preciso sobre la posición y tamaño de los componentes.

JPanel panel = new JPanel(new GridBagLayout());
GridBagConstraints gbc = new GridBagConstraints();

// Ejemplo de configuración de constraints
gbc.gridx = 0; // columna
gbc.gridy = 0; // fila
gbc.gridwidth = 2; // ocupa 2 columnas
gbc.gridheight = 1; // ocupa 1 fila
gbc.weightx = 1.0; // expansión horizontal
gbc.weighty = 0.0; // expansión vertical
gbc.fill = GridBagConstraints.HORIZONTAL;
gbc.insets = new Insets(5,5,5,5); // márgenes

panel.add(new JButton("Botón"), gbc);

5. BoxLayout

Organiza los componentes en una sola fila o columna.

// Vertical
JPanel panel = new JPanel();
panel.setLayout(new BoxLayout(panel, BoxLayout.Y_AXIS));

// O usando Box
Box verticalBox = Box.createVerticalBox();
verticalBox.add(new JButton("Arriba"));
verticalBox.add(Box.createVerticalStrut(10)); // espacio
verticalBox.add(new JButton("Abajo"));
                [Arriba]
                [Abajo]

6. CardLayout

Permite mostrar un componente a la vez, como un mazo de cartas.

CardLayout cards = new CardLayout();
JPanel panel = new JPanel(cards);

panel.add(new JButton("Card 1"), "CARD1");
panel.add(new JButton("Card 2"), "CARD2");

// Cambiar entre cards
cards.show(panel, "CARD1");
cards.next(panel);
cards.previous(panel);

7. SpringLayout

Permite definir relaciones entre los bordes de los componentes.

JPanel panel = new JPanel(new SpringLayout());
JLabel label = new JLabel("Nombre:");
JTextField textField = new JTextField(20);

panel.add(label);
panel.add(textField);

SpringLayout layout = (SpringLayout)panel.getLayout();
layout.putConstraint(SpringLayout.WEST, label, 5, SpringLayout.WEST, panel);
layout.putConstraint(SpringLayout.NORTH, label, 5, SpringLayout.NORTH, panel);
layout.putConstraint(SpringLayout.WEST, textField, 5, SpringLayout.EAST, label);
layout.putConstraint(SpringLayout.NORTH, textField, 5, SpringLayout.NORTH, panel);

8. GroupLayout

Permite definir layouts complejos mediante grupos horizontales y verticales.

JPanel panel = new JPanel();
GroupLayout layout = new GroupLayout(panel);
panel.setLayout(layout);

JLabel label = new JLabel("Usuario:");
JTextField textField = new JTextField();

layout.setHorizontalGroup(
    layout.createSequentialGroup()
        .addComponent(label)
        .addGap(5)
        .addComponent(textField)
);

layout.setVerticalGroup(
    layout.createParallelGroup(GroupLayout.Alignment.BASELINE)
        .addComponent(label)
        .addComponent(textField)
);

Ejemplo Práctico Combinando Layouts

public class EjemploLayouts extends JFrame {
    public EjemploLayouts() {
        setTitle("Ejemplo de Layouts");
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        
        // Panel principal con BorderLayout
        setLayout(new BorderLayout(5, 5));
        
        // Panel superior con FlowLayout
        JPanel topPanel = new JPanel(new FlowLayout(FlowLayout.LEFT));
        topPanel.add(new JButton("Nuevo"));
        topPanel.add(new JButton("Abrir"));
        topPanel.add(new JButton("Guardar"));
        add(topPanel, BorderLayout.NORTH);
        
        // Panel central con GridLayout
        JPanel centerPanel = new JPanel(new GridLayout(2, 2, 5, 5));
        centerPanel.add(new JButton("1"));
        centerPanel.add(new JButton("2"));
        centerPanel.add(new JButton("3"));
        centerPanel.add(new JButton("4"));
        add(centerPanel, BorderLayout.CENTER);
        
        // Panel derecho con BoxLayout
        Box rightPanel = Box.createVerticalBox();
        rightPanel.add(new JButton("Opción 1"));
        rightPanel.add(Box.createVerticalStrut(5));
        rightPanel.add(new JButton("Opción 2"));
        rightPanel.add(Box.createVerticalStrut(5));
        rightPanel.add(new JButton("Opción 3"));
        add(rightPanel, BorderLayout.EAST);
        
        // Panel inferior con FlowLayout
        JPanel bottomPanel = new JPanel(new FlowLayout(FlowLayout.RIGHT));
        bottomPanel.add(new JButton("Aceptar"));
        bottomPanel.add(new JButton("Cancelar"));
        add(bottomPanel, BorderLayout.SOUTH);
        
        pack();
        setLocationRelativeTo(null);
    }
    
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            new EjemploLayouts().setVisible(true);
        });
    }
}

Consejos y Mejores Prácticas

  • Usar el layout apropiado para cada situación
  • Combinar diferentes layouts para crear interfaces complejas
  • Utilizar espaciadores (struts y glue) para mejorar la distribución
  • Considerar el comportamiento de redimensionamiento
  • Mantener la consistencia en los márgenes y espaciado
  • Usar BoxLayout o GridBagLayout para layouts complejos
  • Probar la interfaz con diferentes tamaños de ventana
