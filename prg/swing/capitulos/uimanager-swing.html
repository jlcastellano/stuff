UIManager en Swing

1. Introducción al UIManager

UIManager es una clase que permite personalizar la apariencia y el comportamiento de los componentes Swing a nivel global de la aplicación.

// Establecer Look and Feel
UIManager.setLookAndFeel(UIManager.getSystemLookAndFeelClassName());

// Actualizar componentes existentes
SwingUtilities.updateComponentTreeUI(frame);

2. Look and Feel Disponibles

Swing proporciona varios Look and Feel predefinidos:

// Metal (Look and Feel por defecto)
UIManager.setLookAndFeel("javax.swing.plaf.metal.MetalLookAndFeel");

// Nimbus
UIManager.setLookAndFeel("javax.swing.plaf.nimbus.NimbusLookAndFeel");

// Sistema Operativo
UIManager.setLookAndFeel(UIManager.getSystemLookAndFeelClassName());

// Motif
UIManager.setLookAndFeel("com.sun.java.swing.plaf.motif.MotifLookAndFeel");

3. Personalización de Colores y Fuentes

Modificación de propiedades específicas de los componentes.

// Cambiar color de fondo de botones
UIManager.put("Button.background", new Color(100, 149, 237));

// Cambiar fuente de etiquetas
UIManager.put("Label.font", new Font("Arial", Font.BOLD, 12));

// Cambiar color de selección
UIManager.put("TextField.selectionBackground", Color.ORANGE);
UIManager.put("TextField.selectionForeground", Color.WHITE);

4. Gestión de Defaults

Acceso y modificación de valores por defecto.

// Obtener valores actuales
Color buttonColor = UIManager.getColor("Button.background");
Font labelFont = UIManager.getFont("Label.font");

// Establecer múltiples defaults
UIDefaults defaults = UIManager.getLookAndFeelDefaults();
defaults.put("Panel.background", Color.WHITE);
defaults.put("Panel.font", new Font("SansSerif", Font.PLAIN, 12));

5. Manejo de Errores

Gestión de excepciones al cambiar Look and Feel.

try {
    UIManager.setLookAndFeel(UIManager.getSystemLookAndFeelClassName());
} catch (ClassNotFoundException | InstantiationException |
         IllegalAccessException | UnsupportedLookAndFeelException e) {
    e.printStackTrace();
}

6. Ejemplo Completo de Personalización

public class EjemploUIManager extends JFrame {
    public EjemploUIManager() {
        try {
            // Establecer Look and Feel Nimbus
            UIManager.setLookAndFeel(
                "javax.swing.plaf.nimbus.NimbusLookAndFeel"
            );
            
            // Personalizar componentes
            UIManager.put("Button.background", new Color(70, 130, 180));
            UIManager.put("Button.foreground", Color.WHITE);
            UIManager.put("Panel.background", new Color(240, 240, 240));
            UIManager.put("Label.font", new Font("Segoe UI", Font.PLAIN, 14));
            
            // Crear interfaz
            setTitle("Ejemplo UIManager");
            setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            
            JPanel panel = new JPanel();
            panel.setLayout(new GridLayout(3, 1, 10, 10));
            panel.setBorder(BorderFactory.createEmptyBorder(20, 20, 20, 20));
            
            JLabel label = new JLabel("Ejemplo de UIManager");
            JTextField textField = new JTextField("Campo de texto");
            JButton button = new JButton("Botón personalizado");
            
            panel.add(label);
            panel.add(textField);
            panel.add(button);
            
            add(panel);
            pack();
            setLocationRelativeTo(null);
            
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
    
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            new EjemploUIManager().setVisible(true);
        });
    }
}

8. Mejores Prácticas

  • Establecer el Look and Feel al inicio de la aplicación
  • Usar SwingUtilities.invokeLater() para cambios en la UI
  • Mantener consistencia en el diseño
  • Probar la aplicación en diferentes sistemas operativos
  • Documentar las personalizaciones realizadas
  • Considerar la accesibilidad al personalizar colores
  • Crear temas reutilizables para la aplicación

9. Consideraciones de Rendimiento

  • Realizar cambios de Look and Feel antes de crear componentes
  • Agrupar múltiples cambios de propiedades
  • Evitar cambios frecuentes durante la ejecución
  • Utilizar SwingUtilities.updateComponentTreeUI() con moderación
  • Considerar el impacto en memoria de las personalizaciones
