Contenedores Swing en Java

1. JFrame

Es la ventana principal de una aplicación Swing. Puede contener otros componentes y contenedores.

JFrame frame = new JFrame("Mi Aplicación");
frame.setSize(400, 300);
frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
frame.setVisible(true);

2. JPanel

Un contenedor ligero que puede agrupar y organizar otros componentes.

JPanel panel = new JPanel();
panel.setLayout(new FlowLayout());
panel.add(new JButton("Botón 1"));
panel.add(new JButton("Botón 2"));

3. JScrollPane

Proporciona barras de desplazamiento para componentes que pueden ser más grandes que el área visible.

JTextArea textArea = new JTextArea(20, 30);
JScrollPane scrollPane = new JScrollPane(textArea);

4. JSplitPane

Divide el espacio en dos áreas ajustables mediante una barra divisoria.

JPanel leftPanel = new JPanel();
JPanel rightPanel = new JPanel();
JSplitPane splitPane = new JSplitPane(JSplitPane.HORIZONTAL_SPLIT, leftPanel, rightPanel);

5. JTabbedPane

Permite organizar componentes en pestañas.

JTabbedPane tabbedPane = new JTabbedPane();
tabbedPane.addTab("Pestaña 1", new JPanel());
tabbedPane.addTab("Pestaña 2", new JPanel());

6. JToolBar

Barra de herramientas que puede contener botones y otros componentes.

JToolBar toolBar = new JToolBar();
toolBar.add(new JButton("Nuevo"));
toolBar.add(new JButton("Abrir"));

7. JInternalFrame

Ventanas que se pueden usar dentro de un JDesktopPane para crear aplicaciones MDI (Multiple Document Interface).

JDesktopPane desktop = new JDesktopPane();
JInternalFrame iframe = new JInternalFrame("Ventana Interna", true, true, true, true);
iframe.setSize(200, 200);
iframe.setVisible(true);
desktop.add(iframe);

Ejemplo Completo

import javax.swing.*;
import java.awt.*;

public class EjemploContenedores extends JFrame {
    public EjemploContenedores() {
        setTitle("Ejemplo de Contenedores");
        setSize(600, 400);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        
        // Crear panel principal
        JPanel mainPanel = new JPanel(new BorderLayout());
        
        // Crear barra de herramientas
        JToolBar toolBar = new JToolBar();
        toolBar.add(new JButton("Nuevo"));
        toolBar.add(new JButton("Abrir"));
        mainPanel.add(toolBar, BorderLayout.NORTH);
        
        // Crear panel con pestañas
        JTabbedPane tabbedPane = new JTabbedPane();
        
        // Primera pestaña con split pane
        JSplitPane splitPane = new JSplitPane(
            JSplitPane.HORIZONTAL_SPLIT,
            new JScrollPane(new JTextArea()),
            new JScrollPane(new JList())
        );
        tabbedPane.addTab("Editor", splitPane);
        
        // Segunda pestaña
        tabbedPane.addTab("Configuración", new JPanel());
        
        mainPanel.add(tabbedPane, BorderLayout.CENTER);
        
        setContentPane(mainPanel);
    }
    
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            new EjemploContenedores().setVisible(true);
        });
    }
}

Consideraciones Importantes

  • Todos los contenedores Swing heredan de java.awt.Container
  • Los contenedores pueden anidar otros contenedores
  • Cada contenedor puede tener su propio LayoutManager
  • Los contenedores ligeros (como JPanel) son más eficientes que los pesados (como JFrame)

Mejores Prácticas

  • Usar SwingUtilities.invokeLater() para crear y modificar componentes Swing
  • Establecer siempre una operación por defecto para el cierre de JFrame
  • Utilizar layouts apropiados en lugar de posicionamiento absoluto
  • Considerar la jerarquía de contenedores al diseñar la interfaz
  • Mantener una estructura lógica y organizada de los contenedores
