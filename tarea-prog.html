Aplicación de Gestión E-Commerce

1. Objetivos

Desarrollar una aplicación de escritorio en Java utilizando Swing para la gestión de una tienda online, implementando el patrón MVC y conectando con la base de datos desarrollada en la tarea del módulo de BBDD.

2. Requisitos Funcionales

2.1 Módulo de Gestión de Productos

Interfaz Principal de Productos

  • Tabla de productos con filtros y ordenamiento
  • Formulario de búsqueda avanzada
  • CRUD completo de productos
  • Control de stock con alertas visuales

2.2 Módulo de Gestión de Clientes

Interfaz de Clientes

  • Registro y modificación de datos de cliente
  • Historial de compras por cliente

2.3 Módulo de Gestión de Pedidos

Sistema de Pedidos

  • Creación de pedidos con carrito de compra
  • Proceso de checkout
  • Seguimiento de estado de pedidos

3. Entregables

  1. Código fuente completo (proyecto Maven)

4. Criterios de Evaluación (100 puntos)

Arquitectura y Diseño (30 puntos)

  • Implementación correcta del MVC (15 puntos)
  • Estructura del proyecto (15 puntos)

Funcionalidad (45 puntos)

  • Gestión de productos - CRUD completo y búsqueda (15 puntos)
  • Gestión de clientes - CRUD y historial (15 puntos)
  • Gestión de pedidos - Carrito y seguimiento (15 puntos)

Interfaz de Usuario (25 puntos)

  • Diseño y usabilidad de formularios (10 puntos)
  • Implementación de tablas y filtros (10 puntos)
  • Validaciones y feedback al usuario (5 puntos)

4. Notas Importantes

  • Se valorará la creatividad y funcionalidades adicionales
  • La entrega debe realizarse en un único archivo ZIP (apellido_nombre.zip) con todos los componentes requeridos
