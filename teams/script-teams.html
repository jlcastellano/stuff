Añadir Miembros a Microsoft Teams con PowerShell

Para usar un script de PowerShell con Microsoft Teams para añadir los miembros a partir de los emails, sigue estos pasos detallados.

1. Instalación del Módulo de Microsoft Teams

Primero, instala el módulo si no lo tienes. Debes ejecutar PowerShell como administrador:

Install-Module -Name MicrosoftTeams

2. Conectarse a Microsoft Teams

Después, conéctate a Microsoft Teams ejecutando el siguiente comando:

Connect-MicrosoftTeams

Nota: Esto abrirá una ventana de inicio de sesión donde deberás introducir tus credenciales de Microsoft 365.

3. Ejecutar el Script de Añadir Usuarios

Una vez conectado, puedes ejecutar tu script. Debes copiar el script de abajo y sustituir el teamId y la lista de emails (entre comillas y separados por comas).
Pégalo en un archivo .ps1 para ejecutarlo desde PowerShell. 

# Definir el Team ID y el array de emails
$teamId = "LA_ID_DE_TU_EQUIPO"
$emails = @(
    "email1@digitechfp.com",
    "email2@digitechfp.com"
)

foreach ($email in $emails) {
    try {
        Add-TeamUser -GroupId $teamId -User $email
        Write-Host "Unido correctamente: $email" -ForegroundColor Green
    } catch {
        Write-Host "Error al unir: $email" -ForegroundColor Red
        Write-Host $_.Exception.Message
    }
}

¿Cómo obtengo el Team ID de mi equipo?

Puedes copiar el vínculo que te da en la administración del equipo y quedarte con la cadena después de ?groupId= y antes de &tenantId=

O puedes obtener el Team ID ejecutando el comando Get-Team en PowerShell después de conectarte. Esto listará todos tus equipos con sus respectivos IDs. También puedes usar Get-Team -DisplayName "Nombre de tu equipo" para buscar un equipo específico.
