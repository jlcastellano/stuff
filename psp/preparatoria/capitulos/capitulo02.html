2. Programación de Hilos

Programación de hilos en Java

Los hilos son unidades más ligeras que los procesos y comparten recursos dentro del mismo proceso. En Java podemos crear hilos de dos formas:

Ejemplo 1: Extendiendo Thread


public class MiHilo extends Thread {
    @Override
    public void run() {
        for(int i = 0; i < 5; i++) {
            System.out.println("Hilo " + getName() + ": " + i);
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }

    public static void main(String[] args) {
        MiHilo hilo1 = new MiHilo();
        MiHilo hilo2 = new MiHilo();
        
        hilo1.start();
        hilo2.start();
    }
}

Ejemplo 2: Implementando Runnable


public class MiRunnable implements Runnable {
    @Override
    public void run() {
        for(int i = 0; i < 5; i++) {
            System.out.println("Runnable: " + i);
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }

    public static void main(String[] args) {
        Thread hilo1 = new Thread(new MiRunnable());
        Thread hilo2 = new Thread(new MiRunnable());
        
        hilo1.start();
        hilo2.start();
    }
}

Sincronización de hilos

La sincronización es necesaria cuando varios hilos acceden a recursos compartidos.

Ejemplo: Sincronización con synchronized


public class Contador {
    private int valor = 0;
    
    public synchronized void incrementar() {
        valor++;
    }
    
    public synchronized int getValor() {
        return valor;
    }
}

public class HiloContador extends Thread {
    private Contador contador;
    
    public HiloContador(Contador c) {
        this.contador = c;
    }
    
    @Override
    public void run() {
        for(int i = 0; i < 1000; i++) {
            contador.incrementar();
        }
    }
}

Resumen

  • Los hilos permiten concurrencia dentro de un proceso
  • Se pueden crear extendiendo Thread o implementando Runnable
  • La sincronización es necesaria para recursos compartidos
  • Java ofrece mecanismos de alto nivel para gestión de hilos
