1. Programación de Procesos

Programas y Procesos

Un programa es un conjunto de instrucciones mientras que un proceso es un programa en ejecución. Cada proceso tiene:

  • Código ejecutable
  • Datos
  • Pila
  • Contador de programa
  • Recursos del sistema asignados

Ejemplo: Crear y ejecutar un proceso en Java


public class ProcesoSimple {
    public static void main(String[] args) {
        try {
            // Crear proceso
            ProcessBuilder pb = new ProcessBuilder("notepad.exe");
            Process p = pb.start();
            
            // Esperar a que termine
            int estado = p.waitFor();
            System.out.println("El proceso terminó con estado: " + estado);
            
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

Multitarea

La multitarea permite la ejecución simultánea (real o aparente) de varios procesos. Tipos:

  • Multitarea cooperativa
  • Multitarea apropiativa

Ejemplo: Ejecutar varios procesos


public class MultiProceso {
    public static void main(String[] args) {
        try {
            // Crear varios procesos
            ProcessBuilder pb1 = new ProcessBuilder("calc.exe");
            ProcessBuilder pb2 = new ProcessBuilder("notepad.exe");
            
            Process p1 = pb1.start();
            Process p2 = pb2.start();
            
            // Esperar a que terminen
            p1.waitFor();
            p2.waitFor();
            
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

Concurrencia en Java

Java proporciona varias clases para trabajar con procesos:

  • Runtime: Clase histórica para manejo de procesos
  • Process: Representa un proceso en ejecución
  • ProcessBuilder: Constructor moderno de procesos

Ejemplo: ProcessBuilder con redirección


public class ProcesoConIO {
    public static void main(String[] args) {
        try {
            ProcessBuilder pb = new ProcessBuilder("cmd.exe", "/c", "dir");
            
            // Redirigir salida a un archivo
            pb.redirectOutput(new File("salida.txt"));
            
            // Iniciar proceso
            Process p = pb.start();
            
            // Esperar finalización
            p.waitFor();
            
            System.out.println("Directorio listado en salida.txt");
            
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

Resumen

  • Un proceso es un programa en ejecución
  • Java permite crear y gestionar procesos mediante ProcessBuilder
  • Se pueden redirigir entrada/salida de procesos
  • La multitarea permite ejecutar varios procesos
