5. El Lenguaje SQL: DML y DCL

5.1. Lenguaje de Manipulación de Datos (DML)

5.1.1. La Sentencia SELECT

Estructura Básica:

SELECT [DISTINCT] columna1, columna2, ...
FROM tabla
[WHERE condición]
[GROUP BY columnas]
[HAVING condición_grupo]
[ORDER BY columnas [ASC|DESC]]
[LIMIT n];

Cláusulas Principales:

Cláusula Descripción Ejemplo
SELECT Especifica las columnas a recuperar SELECT nombre, edad
DISTINCT Elimina duplicados SELECT DISTINCT departamento
FROM Especifica la tabla origen FROM empleados
WHERE Filtra registros WHERE edad > 25
ORDER BY Ordena resultados ORDER BY apellido DESC

Ejemplos Prácticos:

-- Selección básica
SELECT nombre, apellido, salario 
FROM empleados 
WHERE salario > 30000;

-- Uso de DISTINCT
SELECT DISTINCT departamento 
FROM empleados;

-- Ordenación múltiple
SELECT nombre, salario, departamento 
FROM empleados 
ORDER BY salario DESC, nombre ASC;

-- Uso de LIMIT
SELECT nombre, salario 
FROM empleados 
ORDER BY salario DESC 
LIMIT 5;

Consejos de Optimización:

  • Evitar SELECT * cuando no se necesiten todas las columnas
  • Usar índices en columnas frecuentemente consultadas
  • Limitar resultados con LIMIT cuando sea posible
  • Usar DISTINCT solo cuando sea necesario

5.1.2. Consulta de Registros sobre una Tabla

Operadores de Comparación:

Operador Descripción Ejemplo
=, !=, >, <, >=, <= Comparaciones básicas WHERE edad >= 18
BETWEEN Rango inclusivo WHERE salario BETWEEN 30000 AND 50000
IN Lista de valores WHERE departamento IN ('IT', 'RRHH')
LIKE Patrón de texto WHERE nombre LIKE 'A%'
IS NULL Valores nulos WHERE telefono IS NULL

Operadores Lógicos:

-- AND
SELECT * FROM empleados 
WHERE salario > 30000 AND departamento = 'IT';

-- OR
SELECT * FROM empleados 
WHERE ciudad = 'Madrid' OR ciudad = 'Barcelona';

-- NOT
SELECT * FROM empleados 
WHERE NOT departamento = 'Ventas';

-- Combinación de operadores
SELECT * FROM empleados 
WHERE (departamento = 'IT' OR departamento = 'RRHH') 
AND salario > 25000;

Ejemplos Avanzados:

-- Búsqueda con patrones
SELECT nombre, email 
FROM empleados 
WHERE email LIKE '%.com' 
AND nombre LIKE 'J%';

-- Rangos de fechas
SELECT nombre, fecha_contrato 
FROM empleados 
WHERE fecha_contrato BETWEEN '2020-01-01' AND '2020-12-31';

-- Múltiples condiciones
SELECT nombre, salario, departamento 
FROM empleados 
WHERE salario > 40000 
AND (departamento = 'IT' OR departamento = 'Finanzas') 
AND fecha_contrato >= '2019-01-01';

5.1.3. Funciones de Agregación

Funciones Principales:

Función Descripción Ejemplo
COUNT() Cuenta registros COUNT(*) o COUNT(columna)
SUM() Suma valores SUM(salario)
AVG() Promedio AVG(salario)
MAX() Valor máximo MAX(salario)
MIN() Valor mínimo MIN(fecha_contrato) 
-- Ejemplos de agregación
SELECT 
    COUNT(*) as total_empleados,
    AVG(salario) as salario_promedio,
    MAX(salario) as salario_maximo,
    MIN(salario) as salario_minimo
FROM empleados;

-- Agregación con GROUP BY
SELECT 
    departamento,
    COUNT(*) as num_empleados,
    AVG(salario) as salario_promedio
FROM empleados
GROUP BY departamento
HAVING COUNT(*) > 5;
