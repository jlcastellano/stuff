5.1.4. Consulta de Registros sobre Varias Tablas. Composiciones

Tipos de JOINS:

INNER JOIN:     A ∩ B
LEFT JOIN:      A ∪ (A ∩ B)
RIGHT JOIN:     (A ∩ B) ∪ B
FULL JOIN:      A ∪ B
                
-- INNER JOIN
SELECT e.nombre, d.nombre_dept
FROM empleados e
INNER JOIN departamentos d 
    ON e.id_departamento = d.id;

-- LEFT JOIN
SELECT e.nombre, d.nombre_dept
FROM empleados e
LEFT JOIN departamentos d 
    ON e.id_departamento = d.id;

-- RIGHT JOIN
SELECT e.nombre, d.nombre_dept
FROM empleados e
RIGHT JOIN departamentos d 
    ON e.id_departamento = d.id;

-- Múltiples JOINS
SELECT e.nombre, d.nombre_dept, p.nombre_proyecto
FROM empleados e
INNER JOIN departamentos d 
    ON e.id_departamento = d.id
INNER JOIN proyectos p 
    ON e.id_proyecto = p.id;

5.1.5. Combinación de Consultas

Operadores de Conjunto:

  • UNION: Combina y elimina duplicados
  • UNION ALL: Combina manteniendo duplicados
  • INTERSECT: Registros comunes
  • EXCEPT: Diferencia de conjuntos
-- UNION
SELECT ciudad FROM empleados
UNION
SELECT ciudad FROM clientes;

-- UNION ALL
SELECT departamento, salario FROM empleados2020
UNION ALL
SELECT departamento, salario FROM empleados2021;

-- INTERSECT
SELECT id_cliente FROM pedidos2020
INTERSECT
SELECT id_cliente FROM pedidos2021;

-- EXCEPT
SELECT id_producto FROM productos
EXCEPT
SELECT id_producto FROM pedidos;

5.1.6. Subconsultas

Tipos de Subconsultas:

  • Escalares (retornan un valor)
  • De lista (retornan múltiples valores)
  • De tabla (retornan una tabla)
-- Subconsulta escalar
SELECT nombre, salario
FROM empleados
WHERE salario > (
    SELECT AVG(salario) 
    FROM empleados
);

-- Subconsulta de lista
SELECT nombre
FROM empleados
WHERE id_departamento IN (
    SELECT id_departamento
    FROM departamentos
    WHERE ubicacion = 'Madrid'
);

-- Subconsulta correlacionada
SELECT e.nombre, e.salario
FROM empleados e
WHERE salario > (
    SELECT AVG(salario)
    FROM empleados
    WHERE departamento = e.departamento
);

5.1.10. Modificación de Registros

-- Actualización simple
UPDATE empleados
SET salario = salario * 1.1
WHERE departamento = 'IT';

-- Actualización con JOIN
UPDATE empleados e
JOIN departamentos d ON e.id_departamento = d.id
SET e.salario = e.salario * 1.15
WHERE d.nombre = 'Ventas';

-- Actualización con subconsulta
UPDATE empleados
SET nivel = 'Senior'
WHERE id IN (
    SELECT id 
    FROM evaluaciones 
    WHERE puntuacion > 90
);

5.1.11. Eliminación de Registros

-- Eliminación simple
DELETE FROM empleados
WHERE fecha_contrato < '2010-01-01';

-- Eliminación con JOIN
DELETE e
FROM empleados e
JOIN departamentos d ON e.id_departamento = d.id
WHERE d.activo = 0;

-- Truncar tabla
TRUNCATE TABLE empleados_temp;

¡Precauciones!

  • Siempre hacer backup antes de DELETE masivos
  • Usar WHERE para evitar eliminaciones no deseadas
  • Verificar con SELECT antes de DELETE
  • TRUNCATE no se puede deshacer

5.2. Lenguaje de Control de Datos (DCL)

5.2.1. Control de Acceso a los Datos

-- Crear usuario
CREATE USER 'usuario1'@'localhost' 
IDENTIFIED BY 'password';

-- Otorgar privilegios
GRANT SELECT, INSERT ON empresa.empleados 
TO 'usuario1'@'localhost';

-- Revocar privilegios
REVOKE INSERT ON empresa.empleados 
FROM 'usuario1'@'localhost';

-- Ver privilegios
SHOW GRANTS FOR 'usuario1'@'localhost';
