3. Variables locales

Las variables son elementos de datos con un nombre cuyo valor puede ir cambiando a lo largo de la ejecución del programa.

Sintaxis:

DECLARE nombre_variable1 [,nombre_variable2...] tipo [DEFAULT valor];

La declaración de variables se realiza antes del comienzo de las instrucciones (y antes de los cursores y manejadores de errores que se verá también en este curso)

De la sintaxis anterior se deduce que se pueden declarar varias variables del mismo tipo seguidas y separadas por comas. Al mismo tiempo que se declaran las variables se pueden definir asignándoles un valor inicial mediante la cláusula DEFAULT; si no se les asigna ninguno entonces las variables quedan definidas al valor NULL. En el momento de la declaración hay que indicar el tipo de datos de la variable; pueden utilizarse cualquiera de los que se emplean en el momento de crear tablas mediante la instrucción CREATE TABLE.

Ejemplo:

DECLARE mivariable INT DEFAULT 10;

Otro ejemplo, ahora dentro de un procedimiento:

DELIMITER $$
DROP PROCEDURE IF EXISTS variables1 $$
CREATE PROCEDURE variables1()
BEGIN
    DECLARE v_numero INT DEFAULT 100;
    SELECT v_numero;
END $$
DELIMITER ;

Para asignar valores a variables se utiliza la siguiente sintaxis:

SET nombre_variable1 = expresión1 [,nombre_variable2 = expresión2 ...]

En este caso y a diferencia de otros lenguajes es necesario especificar la sentencia SET para asignar valores a las variables. Se puede en una sola instrucción realizar varias asignaciones.

Ejemplo:

DELIMITER $$
DROP PROCEDURE IF EXISTS variables2 $$
CREATE PROCEDURE variables2()
BEGIN
    DECLARE v_numero1, v_numero2 INT;
    SET v_numero1 = 100, v_numero2 = 200;
    SELECT v_numero1, v_numero2;
END $$
DELIMITER ;
