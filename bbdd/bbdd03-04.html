3.4. Otras Consideraciones sobre el Modelo Relacional

3.4.1. Índices

Estructuras que mejoran el rendimiento de las consultas.

Tipos de Índices:

  • Índice Clúster: Define el orden físico de los datos
  • Índice No Clúster: Mantiene punteros a los datos
  • Índice Único: No permite valores duplicados
  • Índice Compuesto: Sobre múltiples columnas
CREATE INDEX idx_apellido ON EMPLEADOS(apellido);
CREATE UNIQUE INDEX idx_email ON EMPLEADOS(email);

Consideraciones de Rendimiento:

  • Los índices mejoran las búsquedas pero ralentizan las inserciones
  • No crear índices innecesarios
  • Mantener los índices regularmente

3.4.2. Vistas

Tablas virtuales basadas en el resultado de una consulta SQL.

Tipos de Vistas:

  • Vistas Simples: Basadas en una tabla
  • Vistas Complejas: Involucran múltiples tablas
  • Vistas Materializadas: Almacenan datos físicamente
CREATE VIEW empleados_dept AS
SELECT e.nombre, d.nombre_dept
FROM EMPLEADOS e
JOIN DEPARTAMENTOS d ON e.id_dept = d.id;

3.4.3. Restricciones sobre Campos

Tipos de Restricciones:

  • NOT NULL: No permite valores nulos
  • UNIQUE: Valores únicos
  • CHECK: Condiciones personalizadas
  • DEFAULT: Valor por defecto
ALTER TABLE EMPLEADOS
ADD CONSTRAINT chk_salario 
CHECK (salario >= 0);

ALTER TABLE EMPLEADOS
ADD CONSTRAINT chk_edad 
CHECK (edad >= 18);

3.4.4. Integridad Referencial

Acciones Referenciales:

  • CASCADE: Propaga los cambios
  • SET NULL: Establece valores nulos
  • SET DEFAULT: Establece valores por defecto
  • NO ACTION: Previene cambios que violan la integridad
FOREIGN KEY (id_dept) REFERENCES DEPARTAMENTOS(id)
ON DELETE CASCADE
ON UPDATE CASCADE

3.4.5. Usuarios y Privilegios

Niveles de Privilegios:

  • SELECT: Consultar datos
  • INSERT: Insertar registros
  • UPDATE: Modificar datos
  • DELETE: Eliminar registros
  • EXECUTE: Ejecutar procedimientos
GRANT SELECT, INSERT ON empleados TO usuario1;
REVOKE DELETE ON empleados FROM usuario2;

3.4.6. Accesos Concurrentes

Problemas de Concurrencia:

  • Pérdida de actualización
  • Lecturas sucias
  • Lecturas no repetibles
  • Lecturas fantasma

Niveles de Aislamiento:

  • READ UNCOMMITTED
  • READ COMMITTED
  • REPEATABLE READ
  • SERIALIZABLE

3.4.7. Políticas de Bloqueo

Tipos de Bloqueos:

  • Bloqueo Compartido (S): Para lecturas
  • Bloqueo Exclusivo (X): Para escrituras
  • Bloqueo de Actualización (U): Para actualizaciones
  • Bloqueo de Intención (I): Para jerarquías

Matriz de Compatibilidad de Bloqueos:

S X
S Sí No
X No No

Consideraciones sobre Bloqueos:

  • Evitar bloqueos prolongados
  • Gestionar deadlocks
  • Optimizar transacciones
  • Monitorear bloqueos
