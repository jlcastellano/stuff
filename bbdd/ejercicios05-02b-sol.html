Ejercicios de Control de Acceso a Datos en SQL

Ejercicio 1: Gestión Básica de Usuarios

Crea tres usuarios con las siguientes características:

  • Usuario 'admin_local' que solo pueda conectarse desde localhost
  • Usuario 'vendedor' que pueda conectarse desde cualquier host
  • Usuario 'invitado' que use autenticación mediante mysql_native_password
Dificultad: Básica
-- Crear usuario admin_local CREATE USER 'admin_local'@'localhost' IDENTIFIED BY 'password123'; -- Crear usuario vendedor CREATE USER 'vendedor'@'%' IDENTIFIED BY 'password456'; -- Crear usuario invitado CREATE USER 'invitado'@'localhost' IDENTIFIED WITH mysql_native_password BY 'password789';

Ejercicio 2: Privilegios por Departamento

Para una base de datos 'empresa', configura los siguientes roles y privilegios:

  • Rol 'rol_ventas': acceso de lectura a las tablas 'productos' y 'clientes', y permiso de escritura en 'ventas'
  • Rol 'rol_inventario': acceso completo a la tabla 'productos' y solo lectura en 'ventas'
Dificultad: Intermedia
-- Crear roles CREATE ROLE 'rol_ventas', 'rol_inventario'; -- Configurar privilegios para rol_ventas GRANT SELECT ON empresa.productos TO 'rol_ventas'; GRANT SELECT ON empresa.clientes TO 'rol_ventas'; GRANT ALL PRIVILEGES ON empresa.ventas TO 'rol_ventas'; -- Configurar privilegios para rol_inventario GRANT ALL PRIVILEGES ON empresa.productos TO 'rol_inventario'; GRANT SELECT ON empresa.ventas TO 'rol_inventario';

Ejercicio 3: Vistas Seguras

Crea una vista llamada 'empleados_publicos' que muestre solo el nombre, departamento y años de servicio de los empleados, excluyendo información sensible como salarios. Asigna permisos de lectura a esta vista para el rol 'rol_publico'.

Dificultad: Intermedia
-- Crear la vista CREATE VIEW empleados_publicos AS SELECT nombre, departamento, TIMESTAMPDIFF(YEAR, fecha_ingreso, CURRENT_DATE) as años_servicio FROM empleados; -- Crear rol público CREATE ROLE 'rol_publico'; -- Asignar permisos a la vista GRANT SELECT ON empresa.empleados_publicos TO 'rol_publico';

Ejercicio 4: Gestión de Permisos Específicos

Configura los siguientes permisos para el usuario 'analista_datos':

  • Permiso de lectura en todas las tablas de la base de datos 'ventas2023'
  • Permiso de actualización solo en la columna 'estado' de la tabla 'pedidos'
  • Sin permiso para eliminar registros en ninguna tabla
Dificultad: Avanzada
-- Crear usuario analista_datos CREATE USER 'analista_datos'@'localhost' IDENTIFIED BY 'password123'; -- Asignar permisos de lectura en toda la base de datos GRANT SELECT ON ventas2023.* TO 'analista_datos'@'localhost'; -- Asignar permiso de actualización específico GRANT UPDATE (estado) ON ventas2023.pedidos TO 'analista_datos'@'localhost';

Ejercicio 5: Roles Jerárquicos

Implementa una estructura de roles jerárquica para un sistema de gestión escolar:

  • Rol 'director': acceso completo a todas las tablas
  • Rol 'profesor': acceso a notas y asistencias de sus propias clases
  • Rol 'estudiante': solo lectura de sus propias notas
Dificultad: Avanzada
-- Crear roles CREATE ROLE 'director', 'profesor', 'estudiante'; -- Configurar rol director GRANT ALL PRIVILEGES ON escuela.* TO 'director'; -- Configurar rol profesor GRANT SELECT, INSERT, UPDATE ON escuela.notas TO 'profesor'; GRANT SELECT, INSERT, UPDATE ON escuela.asistencias TO 'profesor'; GRANT SELECT ON escuela.estudiantes TO 'profesor'; -- Configurar rol estudiante GRANT SELECT ON escuela.notas_vista TO 'estudiante'; -- Crear vista para estudiantes CREATE VIEW notas_vista AS SELECT n.* FROM notas n WHERE n.estudiante_id = CURRENT_USER();

Ejercicio 6: Auditoría de Accesos

Configura un sistema de auditoría que:

  • Registre todos los intentos de acceso fallidos
  • Guarde un log de todas las modificaciones en la tabla 'empleados'
  • Crea una consulta que muestre estas actividades
Dificultad: Avanzada
-- Habilitar log general SET GLOBAL general_log = 'ON'; SET GLOBAL general_log_file = '/var/log/mysql/mysql.log'; -- Crear tabla de auditoría CREATE TABLE auditoria_empleados ( id INT AUTO_INCREMENT PRIMARY KEY, accion VARCHAR(50), usuario VARCHAR(100), fecha TIMESTAMP, datos_antiguos TEXT, datos_nuevos TEXT ); -- Crear trigger para auditoría DELIMITER // CREATE TRIGGER audit_empleados_update AFTER UPDATE ON empleados FOR EACH ROW BEGIN INSERT INTO auditoria_empleados (accion, usuario, fecha, datos_antiguos, datos_nuevos) VALUES ('UPDATE', CURRENT_USER(), NOW(), JSON_OBJECT('old', OLD.nombre, 'old_salary', OLD.salario), JSON_OBJECT('new', NEW.nombre, 'new_salary', NEW.salario)); END; // DELIMITER ; -- Consulta para ver actividades SELECT * FROM auditoria_empleados ORDER BY fecha DESC;

Ejercicio 7: Gestión de Contraseñas

Implementa una política de contraseñas que incluya:

  • Cambio obligatorio cada 30 días
  • Mínimo 8 caracteres con combinación de letras y números
  • Bloqueo de cuenta tras 3 intentos fallidos
Dificultad: Intermedia
-- Configurar política de contraseñas SET GLOBAL validate_password.policy = MEDIUM; SET GLOBAL validate_password.length = 8; SET GLOBAL validate_password.mixed_case_count = 1; SET GLOBAL validate_password.number_count = 1; -- Configurar expiración de contraseña ALTER USER 'usuario1'@'localhost' PASSWORD EXPIRE INTERVAL 30 DAY; -- Configurar bloqueo tras intentos fallidos CREATE TABLE login_attempts ( id INT AUTO_INCREMENT PRIMARY KEY, username VARCHAR(100), attempt_time TIMESTAMP, attempts INT DEFAULT 1 ); DELIMITER // CREATE TRIGGER check_login_attempts BEFORE UPDATE ON mysql.user FOR EACH ROW BEGIN IF (SELECT attempts FROM login_attempts WHERE username = USER() AND attempt_time > NOW() - INTERVAL 1 HOUR) >= 3 THEN SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = 'Account locked due to too many failed attempts'; END IF; END; // DELIMITER ;

Ejercicio 8: Restricciones de Acceso Temporal

Configura accesos temporales para usuarios de mantenimiento:

  • Usuario que solo pueda conectarse en horario laboral (9:00-18:00)
  • Usuario con acceso completo pero solo durante el fin de semana
Dificultad: Avanzada
-- Crear usuarios de mantenimiento CREATE USER 'mant_diurno'@'localhost' IDENTIFIED BY 'password123'; CREATE USER 'mant_finde'@'localhost' IDENTIFIED BY 'password456'; -- Crear procedimiento para verificar horario DELIMITER // CREATE PROCEDURE check_access_time() BEGIN IF (HOUR(NOW()) < 9 OR HOUR(NOW()) >= 18) THEN SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = 'Acceso permitido solo en horario laboral'; END IF; END; // DELIMITER ; -- Crear trigger para verificar horario DELIMITER // CREATE TRIGGER check_maintenance_access BEFORE CONNECT ON *.* FOR EACH ROW BEGIN IF CURRENT_USER() = 'mant_diurno'@'localhost' THEN CALL check_access_time(); ELSEIF CURRENT_USER() = 'mant_finde'@'localhost' AND WEEKDAY(NOW()) NOT IN (5,6) THEN SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = 'Acceso permitido solo en fin de semana'; END IF; END; // DELIMITER ;
