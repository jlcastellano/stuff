1.3. Bases de Datos

1.3.1. Definición

Una base de datos es una colección organizada de datos estructurados, relacionados entre sí, que son almacenados de forma sistemática para su posterior uso. Las bases de datos están diseñadas para:

  • Gestionar grandes cantidades de información
  • Mantener la integridad de los datos
  • Facilitar la consulta y actualización de datos
  • Permitir el acceso simultáneo de múltiples usuarios

1.3.2. Tipos de Bases de Datos

Bases de Datos Relacionales (SQL)

Organizan datos en tablas con relaciones entre ellas.

Ejemplos: MySQL, PostgreSQL, Oracle, SQL Server
Tabla Clientes:
ID | Nombre | Email | Teléfono
1 | Juan | juan@email.com | 123456789
  • Uso de claves primarias y foráneas
  • Garantía de integridad referencial
  • Soporte ACID (Atomicidad, Consistencia, Aislamiento, Durabilidad)

Bases de Datos No Relacionales (NoSQL)

Diseñadas para modelos de datos específicos sin esquema fijo.

Ejemplos: MongoDB, Cassandra, Redis
{
"id": 1,
"nombre": "Juan",
"contacto": {
"email": "juan@email.com",
"tel": "123456789"
}
}

Bases de Datos Orientadas a Objetos

Almacenan los datos en forma de objetos, similar a la programación orientada a objetos.

Ejemplos: ObjectDB, Versant

Características Fundamentales

Característica Descripción
Independencia de datos Los datos son independientes de las aplicaciones que los utilizan
Integridad Garantía de exactitud y consistencia de los datos
Seguridad Control de acceso y protección de datos
Concurrencia Acceso simultáneo por múltiples usuarios

Ventajas de las Bases de Datos

  • Reducción de redundancia
  • Consistencia de datos
  • Integridad de datos
  • Seguridad mejorada
  • Independencia de datos
  • Acceso compartido
  • Respaldo y recuperación

Elementos Básicos

  • Campos: Unidad mínima de información
  • Registros: Conjunto de campos relacionados
  • Tablas: Conjunto de registros del mismo tipo
  • Relaciones: Conexiones lógicas entre tablas
  • Claves: Identificadores únicos de registros
