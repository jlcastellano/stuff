2.1. Modelización Conceptual del Software

2.1.1. Modelización de Datos

La modelización de datos es el proceso de crear una representación abstracta de los datos y sus relaciones en un sistema.

Fases del Modelado

  • Análisis de requisitos
  • Diseño conceptual
  • Diseño lógico
  • Diseño físico

Ejemplo de Proceso de Modelado:

  1. Identificar entidades principales
  2. Determinar atributos
  3. Establecer relaciones
  4. Definir restricciones

2.1.2. Diccionario de Datos

El diccionario de datos es un repositorio centralizado de información sobre los datos almacenados en la base de datos.

Elementos del Diccionario

Elemento Descripción Ejemplo
Nombre del campo Identificador del campo id_cliente
Tipo de dato Tipo de información INTEGER
Longitud Tamaño del campo 10
Restricciones Reglas del campo NOT NULL

2.1.3. Modelo Conceptual de Datos (MCD)

El MCD es una representación de alto nivel de la estructura de datos de un sistema.

Características del MCD

  • Independencia tecnológica
  • Visión global del sistema
  • Facilita la comunicación con usuarios
  • Base para el diseño lógico

Componentes Principales:

  • Entidades
  • Atributos
  • Relaciones
  • Cardinalidad

Ventajas del MCD

  • Simplicidad y claridad
  • Facilita la validación del diseño
  • Independencia del SGBD
  • Base para la documentación

Proceso de Desarrollo del MCD

  1. Identificación de entidades y atributos
  2. Establecimiento de relaciones
  3. Definición de cardinalidades
  4. Refinamiento del modelo
  5. Validación con usuarios
