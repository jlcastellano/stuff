Ejercicios de Control de Acceso a Datos en SQL

Ejercicio 1: Gestión Básica de Usuarios

Crea tres usuarios con las siguientes características:

  • Usuario 'admin_local' que solo pueda conectarse desde localhost
  • Usuario 'vendedor' que pueda conectarse desde cualquier host
  • Usuario 'invitado' que use autenticación mediante mysql_native_password
Dificultad: Básica

Ejercicio 2: Privilegios por Departamento

Para una base de datos 'empresa', configura los siguientes roles y privilegios:

  • Rol 'rol_ventas': acceso de lectura a las tablas 'productos' y 'clientes', y permiso de escritura en 'ventas'
  • Rol 'rol_inventario': acceso completo a la tabla 'productos' y solo lectura en 'ventas'
Dificultad: Intermedia

Ejercicio 3: Vistas Seguras

Crea una vista llamada 'empleados_publicos' que muestre solo el nombre, departamento y años de servicio de los empleados, excluyendo información sensible como salarios. Asigna permisos de lectura a esta vista para el rol 'rol_publico'.

Dificultad: Intermedia

Ejercicio 4: Gestión de Permisos Específicos

Configura los siguientes permisos para el usuario 'analista_datos':

  • Permiso de lectura en todas las tablas de la base de datos 'ventas2023'
  • Permiso de actualización solo en la columna 'estado' de la tabla 'pedidos'
  • Sin permiso para eliminar registros en ninguna tabla
Dificultad: Avanzada

Ejercicio 5: Roles Jerárquicos

Implementa una estructura de roles jerárquica para un sistema de gestión escolar:

  • Rol 'director': acceso completo a todas las tablas
  • Rol 'profesor': acceso a notas y asistencias de sus propias clases
  • Rol 'estudiante': solo lectura de sus propias notas
Dificultad: Avanzada

Ejercicio 6: Auditoría de Accesos

Configura un sistema de auditoría que:

  • Registre todos los intentos de acceso fallidos
  • Guarde un log de todas las modificaciones en la tabla 'empleados'
  • Crea una consulta que muestre estas actividades
Dificultad: Avanzada

Ejercicio 7: Gestión de Contraseñas

Implementa una política de contraseñas que incluya:

  • Cambio obligatorio cada 30 días
  • Mínimo 8 caracteres con combinación de letras y números
  • Bloqueo de cuenta tras 3 intentos fallidos
Dificultad: Intermedia

Ejercicio 8: Restricciones de Acceso Temporal

Configura accesos temporales para usuarios de mantenimiento:

  • Usuario que solo pueda conectarse en horario laboral (9:00-18:00)
  • Usuario con acceso completo pero solo durante el fin de semana
Dificultad: Avanzada
