4. El Lenguaje SQL - DDL

4.1. Introducción al Lenguaje SQL

¿Qué es SQL?

SQL (Structured Query Language) es un lenguaje estándar para gestionar bases de datos relacionales.

Características Principales:

  • Lenguaje declarativo
  • Estándar ANSI/ISO
  • Maneja conjuntos de datos
  • Integra diferentes operaciones

Sublenguajes SQL:

Sublenguaje Propósito Comandos Principales
DDL (Data Definition Language) Define estructuras de datos CREATE, ALTER, DROP
DML (Data Manipulation Language) Manipula datos SELECT, INSERT, UPDATE, DELETE
DCL (Data Control Language) Controla accesos GRANT, REVOKE
TCL (Transaction Control Language) Controla transacciones COMMIT, ROLLBACK

4.2. Tipos de Datos en SQL

Tipos Numéricos:

Tipo Descripción Rango/Tamaño
INT/INTEGER Entero -2³¹ a 2³¹-1
SMALLINT Entero pequeño -2¹⁵ a 2¹⁵-1
DECIMAL(p,s) Número decimal exacto p dígitos totales, s decimales
FLOAT Punto flotante Precisión variable

Tipos de Caracteres:

Tipo Descripción Uso
CHAR(n) Cadena de longitud fija Códigos, IDs fijos
VARCHAR(n) Cadena de longitud variable Textos variables
TEXT Texto largo Documentos, descripciones

Tipos de Fecha y Hora:

Tipo Descripción Formato
DATE Fecha YYYY-MM-DD
TIME Hora HH:MM:SS
TIMESTAMP Fecha y hora YYYY-MM-DD HH:MM:SS

Otros Tipos:

  • BOOLEAN: Valores true/false
  • BLOB: Datos binarios grandes
  • JSON: Datos en formato JSON
  • XML: Datos en formato XML

Ejemplo de Uso:

CREATE TABLE empleados (
    id INT PRIMARY KEY,
    nombre VARCHAR(50),
    fecha_nacimiento DATE,
    salario DECIMAL(10,2),
    activo BOOLEAN
);
