Ejercicios Prácticos SQL Avanzado

Contexto:

Considera una librería con las siguientes tablas:

CREATE TABLE libros ( id INT PRIMARY KEY, titulo VARCHAR(100), autor_id INT, editorial_id INT, genero VARCHAR(50), precio DECIMAL(10,2), stock INT ); CREATE TABLE autores ( id INT PRIMARY KEY, nombre VARCHAR(100), nacionalidad VARCHAR(50), fecha_nacimiento DATE ); CREATE TABLE editoriales ( id INT PRIMARY KEY, nombre VARCHAR(100), pais VARCHAR(50) ); CREATE TABLE ventas ( id INT PRIMARY KEY, libro_id INT, fecha_venta DATE, cantidad INT, precio_total DECIMAL(10,2) );

Ejercicio 1: INNER JOIN y Funciones de Agregación

Obtener un listado que muestre el nombre del autor, la cantidad total de libros que ha escrito y el valor total de inventario (precio * stock) de sus libros. Mostrar solo los autores que tengan más de 1 libro publicado.

Ejercicio 2: LEFT JOIN y Subconsultas

Encontrar todos los autores que no tienen libros en stock (stock = 0) o no tienen libros publicados. Mostrar el nombre del autor y su nacionalidad.

Ejercicio 3: Subconsultas Correlacionadas

Listar los libros cuyo precio es mayor que el precio promedio de los libros de su mismo género. Mostrar título, género y precio.

Ejercicio 4: UNION y Funciones de Fecha

Crear un reporte que muestre en una sola lista: - Los autores que cumplan años en julio y agosto de este año - Los libros que se hayan vendido entre julio y agosto de 2023 Cada fila debe indicar si es un autor o un libro y la fecha relevante.

Ejercicio 5: Transacciones y Actualizaciones Múltiples

Escribir una transacción que: 1. Registre una nueva venta 2. Actualice el stock del libro 3. Si el stock queda en 0, actualice el precio aumentándolo un 10%

Ejercicio 6: JOIN Múltiple y Funciones de Agregación

Obtener un informe que muestre por cada editorial: - Nombre de la editorial - País - Cantidad de autores diferentes - Total de ventas del último año - Promedio de precio de sus libros

Ejercicio 7: Subconsultas en UPDATE

Actualizar el precio de todos los libros que no han tenido ventas en los últimos 6 meses, aplicando un descuento del 15%.

Ejercicio 8: INSERT con Subconsulta

Crear una tabla de "libros_destacados" e insertar en ella todos los libros que cumplan al menos una de estas condiciones: - Han vendido más de 100 unidades en total - Su precio está por encima del promedio de su género - Son del autor más vendido

Ejercicio 9: DELETE con JOIN

Eliminar todos los registros de ventas de libros cuyas editoriales ya no están activas (no tienen libros en stock).

Ejercicio 10: Vistas y Permisos

Crear una vista que muestre un resumen de ventas por género y mes, y asignar permisos de lectura a un usuario 'analista'.
