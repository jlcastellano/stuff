1.4. Sistemas Gestores de Bases de Datos (SGBD)

¿Qué es un SGBD?

Un Sistema Gestor de Bases de Datos es un software específico diseñado para servir de interfaz entre la base de datos, los usuarios y las aplicaciones. Permite administrar, controlar y gestionar todos los aspectos relacionados con los datos.

1.4.1. Componentes del SGBD

Diccionario de Datos

Almacena metadatos sobre la estructura de la base de datos:

  • Nombres y definiciones de tablas
  • Tipos de datos
  • Restricciones
  • Relaciones entre tablas

Motor de Base de Datos

Componente central que:

  • Gestiona el almacenamiento físico
  • Maneja las transacciones
  • Controla la concurrencia
  • Gestiona los búferes de memoria

Procesador de Consultas

Se encarga de:

  • Interpretar consultas SQL
  • Optimizar consultas
  • Generar planes de ejecución
SELECT nombre, salario
FROM empleados
WHERE departamento = 'IT';

Gestor de Seguridad

  • Control de acceso
  • Gestión de usuarios y roles
  • Encriptación de datos
  • Auditoría

1.4.2. Funciones del SGBD

Definición de Datos (DDL)

Permite crear y modificar la estructura de la base de datos

CREATE TABLE, ALTER TABLE, DROP TABLE

Manipulación de Datos (DML)

Operaciones CRUD (Create, Read, Update, Delete)

INSERT, SELECT, UPDATE, DELETE

Control de Concurrencia

  • Gestión de transacciones
  • Bloqueos
  • Control de versiones

Integridad de Datos

  • Restricciones de integridad
  • Validación de datos
  • Consistencia

Ventajas del uso de SGBD

  • Independencia física y lógica de los datos
  • Integridad y consistencia garantizada
  • Control centralizado
  • Reducción de redundancia
  • Seguridad mejorada
  • Recuperación ante fallos
