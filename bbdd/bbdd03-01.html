3.1. El Modelo Relacional

Conceptos Fundamentales

1. Relación (Tabla)

Una relación es una tabla compuesta por filas (tuplas) y columnas (atributos).

Ejemplo de Relación: EMPLEADOS

ID Nombre Departamento Salario
1 Juan Pérez Ventas 30000
2 Ana López IT 35000

2. Elementos del Modelo Relacional

  • Atributos: Columnas de la tabla
  • Tuplas: Filas de la tabla
  • Dominio: Conjunto de valores posibles para un atributo
  • Clave Primaria: Identificador único de cada tupla
  • Clave Foránea: Referencia a clave primaria de otra tabla

3. Propiedades de las Relaciones

  • No hay tuplas duplicadas
  • El orden de las tuplas no es relevante
  • El orden de los atributos no es relevante
  • Los valores de los atributos son atómicos

4. Restricciones del Modelo Relacional

Restricciones de Dominio

  • Tipo de dato
  • Rango de valores
  • Valores permitidos

Restricciones de Clave

  • Unicidad
  • No nulidad

Restricciones de Integridad Referencial

Si un departamento está referenciado en la tabla EMPLEADOS, debe existir en la tabla DEPARTAMENTOS.

5. Operaciones Básicas

                
                SELECT * FROM Empleados WHERE Departamento = 'IT';

                
                SELECT Nombre, Salario FROM Empleados;

                
                SELECT * FROM Empleados1 UNION SELECT * FROM Empleados2;

                
                SELECT * FROM Empleados1 EXCEPT SELECT * FROM Empleados2;

                
                SELECT * FROM Empleados CROSS JOIN Departamentos;

6. Ventajas del Modelo Relacional

  • Simplicidad y uniformidad
  • Independencia física de los datos
  • Independencia lógica de los datos
  • Facilidad de uso
  • Integridad de datos
  • Flexibilidad

Ejemplo Práctico de Relaciones

DEPARTAMENTOS

ID_Dept Nombre Ubicación
1 IT Madrid
2 Ventas Barcelona

EMPLEADOS

ID_Emp Nombre ID_Dept
1 Juan Pérez 1
2 Ana López 2
