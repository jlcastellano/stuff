3.3. Paso del DER al Modelo Físico de Datos

3.3.1. Nomenclatura

Convenciones de Nombres

  • Tablas:
    • Nombre en plural
    • Sin espacios ni caracteres especiales
    • Preferiblemente mayúsculas
  • Campos:
    • Nombre descriptivo
    • Prefijo de la tabla para claves foráneas
    • ID_ para claves primarias
  • Restricciones:
    • PK_: Para claves primarias
    • FK_: Para claves foráneas
    • UQ_: Para restricciones únicas
    • CK_: Para checks

Ejemplos de Nomenclatura:

  • Tabla: EMPLEADOS
  • Clave Primaria: ID_EMPLEADO
  • Clave Foránea: ID_DEPARTAMENTO
  • Restricción: PK_EMPLEADOS

3.3.2. Reglas de Transformación

1. Transformación de Entidades

Cada entidad se convierte en una tabla

                    CREATE TABLE EMPLEADOS (
                        ID_EMPLEADO INT PRIMARY KEY,
                        NOMBRE VARCHAR(50),
                        APELLIDO VARCHAR(50)
                    );

2. Transformación de Atributos

  • Atributos simples → Columnas
  • Atributos compuestos → Múltiples columnas o nueva tabla
  • Atributos multivaluados → Nueva tabla

3. Transformación de Relaciones

Según la cardinalidad:

  • 1:1: Clave foránea en cualquiera de las tablas
  • 1:N: Clave foránea en la tabla del lado N
  • N:M: Nueva tabla con ambas claves foráneas

4. Transformación de Herencia

  • Tabla única con todos los atributos
  • Una tabla por cada subclase
  • Tabla para superclase y subclases

3.3.3. Ejemplo de Transformación de DER a Modelo Físico

DER Original:

EMPLEADO (1:N) trabaja_en DEPARTAMENTO
Atributos Empleado: ID, Nombre, Dirección
Atributos Departamento: ID, Nombre, Ubicación

Transformación a Modelo Físico:

CREATE TABLE DEPARTAMENTOS (
    ID_DEPARTAMENTO INT PRIMARY KEY,
    NOMBRE VARCHAR(50),
    UBICACION VARCHAR(100)
);

CREATE TABLE EMPLEADOS (
    ID_EMPLEADO INT PRIMARY KEY,
    NOMBRE VARCHAR(50),
    DIRECCION VARCHAR(100),
    ID_DEPARTAMENTO INT,
    FOREIGN KEY (ID_DEPARTAMENTO) 
    REFERENCES DEPARTAMENTOS(ID_DEPARTAMENTO)
);

Ejemplo de Relación N:M

ESTUDIANTE (N:M) matricula CURSO
                
CREATE TABLE ESTUDIANTES (
    ID_ESTUDIANTE INT PRIMARY KEY,
    NOMBRE VARCHAR(50)
);

CREATE TABLE CURSOS (
    ID_CURSO INT PRIMARY KEY,
    NOMBRE VARCHAR(50)
);

CREATE TABLE MATRICULAS (
    ID_ESTUDIANTE INT,
    ID_CURSO INT,
    FECHA_MATRICULA DATE,
    PRIMARY KEY (ID_ESTUDIANTE, ID_CURSO),
    FOREIGN KEY (ID_ESTUDIANTE) 
    REFERENCES ESTUDIANTES(ID_ESTUDIANTE),
    FOREIGN KEY (ID_CURSO) 
    REFERENCES CURSOS(ID_CURSO)
);
