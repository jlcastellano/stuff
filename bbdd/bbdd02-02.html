2.2. Diagrama Entidad/Relación (DER)

2.2.1. Entidad

Una entidad es un objeto o concepto del mundo real que se puede distinguir de otros objetos.

Tipos de Entidades:

  • Entidades Fuertes: Existencia independiente
  • Entidades Débiles: Dependen de otra entidad
E

Representación: Rectángulo

Ejemplos de entidades:
  • CLIENTE (Fuerte)
  • FACTURA (Débil)
  • PRODUCTO (Fuerte)

2.2.2. Relación

Asociación entre entidades que representa una dependencia o conexión entre ellas.

R

Representación: Rombo

Tipos de Relaciones:

  • Binarias (entre dos entidades)
  • Ternarias (entre tres entidades)
  • Recursivas (entidad consigo misma)

2.2.3. Cardinalidad y Modalidad

Cardinalidad:

Tipo Significado Notación
Uno a Uno (1:1) Un elemento se relaciona con exactamente otro 1 — 1
Uno a Muchos (1:N) Un elemento se relaciona con varios 1 — N
Muchos a Muchos (N:M) Varios elementos se relacionan con varios N — M

Modalidad:

  • Obligatoria (|): Participación requerida
  • Opcional (O): Participación no requerida

2.2.4. Atributos de Relación

A

Representación: Óvalo

Tipos de Atributos:

  • Simples: Valor atómico
  • Compuestos: Pueden dividirse
  • Monovaluados: Un solo valor
  • Multivaluados: Múltiples valores
  • Derivados: Calculados de otros atributos

2.2.5. Clave Primaria y Claves Candidatas

Clave Primaria:

  • Identifica unívocamente cada instancia
  • No puede contener valores nulos
  • Debe ser mínima

Claves Candidatas:

  • Atributos que podrían ser clave primaria
  • Cumplen con unicidad
  • No redundantes

2.2.6. Ejemplo de Diagrama Entidad/Relación

                [CLIENTE] -------- [PRODUCTO]

                |  |  |                     |  |  |

                id  nombre  email           id  nombre  precio

                (1:N)                      (N:1)

Explicación del ejemplo:

  • Entidades: CLIENTE y PRODUCTO
  • Relación: compra
  • Cardinalidad: Un cliente puede comprar muchos productos (1:N)
  • Atributos: id, nombre, email (CLIENTE) / id, nombre, precio (PRODUCTO)
