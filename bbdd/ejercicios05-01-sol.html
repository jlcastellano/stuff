Ejercicios Prácticos SQL: DML

Contexto:

Considera una base de datos de una biblioteca con la siguiente tabla:

CREATE TABLE libros ( id INT PRIMARY KEY, titulo VARCHAR(100), autor VARCHAR(100), genero VARCHAR(50), año_publicacion INT, precio DECIMAL(10,2), copias_disponibles INT, editorial VARCHAR(100) );

Ejercicio 1: Consulta Básica con Filtros y Ordenamiento

Escribe una consulta SQL que muestre el título, autor y precio de todos los libros de "Ciencia Ficción" publicados después del año 2000, ordenados por precio de mayor a menor. Incluye solo los libros que tengan un precio superior a 20€.

SELECT titulo, autor, precio FROM libros WHERE genero = 'Ciencia Ficción' AND año_publicacion > 2000 AND precio > 20 ORDER BY precio DESC;

Ejercicio 2: Uso de Funciones de Agregación y GROUP BY

Genera una consulta que muestre, para cada editorial, el número total de libros, el precio promedio y el número de copias disponibles. Incluye solo las editoriales que tengan más de 5 libros en total y un precio promedio superior a 30€.

SELECT editorial, COUNT(*) as total_libros, AVG(precio) as precio_promedio, SUM(copias_disponibles) as total_copias FROM libros GROUP BY editorial HAVING COUNT(*) > 5 AND AVG(precio) > 30;

Ejercicio 3: Consulta con Operadores Múltiples

Escribe una consulta que encuentre todos los libros que cumplan con las siguientes condiciones:

  • Pertenezcan al género "Fantasía" o "Aventura"
  • Tengan un precio entre 15€ y 50€
  • El título comience con la letra 'E'
  • Tengan al menos 3 copias disponibles
Muestra el título, género, precio y copias disponibles.

SELECT titulo, genero, precio, copias_disponibles FROM libros WHERE (genero = 'Fantasía' OR genero = 'Aventura') AND precio BETWEEN 15 AND 50 AND titulo LIKE 'E%' AND copias_disponibles >= 3;
