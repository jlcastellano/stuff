Ejercicios de Triggers en MySQL

Ejercicio 1 - Sistema de Inventario con Histórico

Crear un sistema de triggers que mantenga un registro histórico de los cambios en el inventario de productos. Se debe:

  • Registrar toda modificación del stock en una tabla de histórico
  • Almacenar quién realizó el cambio, cuándo y el tipo de operación
  • Mantener el stock mínimo y máximo permitido

Tablas necesarias: productos(id, nombre, stock, stock_minimo, stock_maximo) y productos_historico(id, producto_id, usuario, fecha, operacion, stock_anterior, stock_nuevo)

Ejercicio 2 - Validación de Empleados

Implementar triggers para validar datos de empleados al insertar o actualizar:

  • El salario no puede ser negativo ni mayor a 100,000
  • La edad debe estar entre 18 y 65 años
  • El email debe tener un formato válido
  • Registrar cambios de salario en una tabla de auditoría

Tablas: empleados(id, nombre, email, fecha_nacimiento, salario) y auditoria_salarios(id, empleado_id, salario_anterior, salario_nuevo, fecha_cambio)

Ejercicio 3 - Sistema de Calificaciones

Crear triggers para un sistema de calificaciones que:

  • Calcule automáticamente el promedio del estudiante al insertar/actualizar notas
  • Valide que las calificaciones estén entre 0 y 10
  • Actualice el estado del estudiante (aprobado/reprobado) según su promedio
  • Mantenga un historial de cambios de calificaciones

Tablas: estudiantes(id, nombre, promedio, estado), calificaciones(id, estudiante_id, materia_id, nota) y historial_calificaciones(id, estudiante_id, materia_id, nota_anterior, nota_nueva, fecha_cambio)

Ejercicio 4 - Control de Pedidos

Implementar triggers para un sistema de pedidos que:

  • Actualice automáticamente el stock al crear/modificar pedidos
  • Valide que hay stock suficiente
  • Calcule el total del pedido automáticamente
  • Registre los cambios en el estado del pedido

Tablas: pedidos(id, cliente_id, total, estado), detalle_pedido(id, pedido_id, producto_id, cantidad, precio), productos(id, nombre, stock) y log_pedidos(id, pedido_id, estado_anterior, estado_nuevo, fecha_cambio)

Ejercicio 5 - Sistema Bancario

Desarrollar triggers para un sistema bancario que:

  • Valide el saldo disponible antes de realizar retiros
  • Mantenga un registro de todas las transacciones
  • Actualice el saldo de las cuentas automáticamente
  • Controle límites diarios de transacciones

Tablas: cuentas(id, cliente_id, saldo), transacciones(id, cuenta_id, tipo, monto, fecha) y limites_diarios(cuenta_id, fecha, monto_total)

El sistema funciona con la tabla transacciones como elemento principal que controla al resto.

Ejercicio 6 - Sistema de Biblioteca

Crear triggers para un sistema de biblioteca que:

  • Controle el préstamo y devolución de libros
  • Mantenga el inventario actualizado
  • Registre multas por retrasos automáticamente
  • Valide el número máximo de préstamos por usuario

Tablas: libros(id, titulo, copias_disponibles), prestamos(id, libro_id, usuario_id, fecha_prestamo, fecha_devolucion, estado), usuarios(id, nombre, prestamos_activos) y multas(id, usuario_id, monto, fecha, pagada)
