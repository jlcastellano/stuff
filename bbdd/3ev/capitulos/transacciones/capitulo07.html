7. Cómo realizar transacciones con procedimientos almacenados

Podemos utilizar el manejo de errores para decidir si hacemos ROLLBACK de una transacción en un Store Procedure. En el siguiente ejemplo vamos a capturar los errores que se produzcan de tipo SQLEXCEPTION.

Ejemplo de Procedimiento Almacenado con Transacción

DELIMITER $$

CREATE PROCEDURE transaccion_en_mysql(usuario_id INT, libro_id INT)
BEGIN
    DECLARE EXIT HANDLER FOR SQLEXCEPTION  -- OCURRE UN ERROR
    BEGIN
        ROLLBACK;
    END;

    START TRANSACTION;
    -- Sentencias SQL
    INSERT INTO prestamos(id_libro, id_usuario) VALUES(libro_id, usuario_id);
    UPDATE libros SET stock = stock - 1 WHERE id_libro = libro_id;
    COMMIT;
END $$

DELIMITER ;

Análisis del Código

  • DECLARE EXIT HANDLER FOR SQLEXCEPTION: Define qué hacer cuando ocurre un error SQL
  • BEGIN ROLLBACK; END: En caso de error, se deshacen todos los cambios
  • START TRANSACTION: Inicia la transacción
  • Sentencias SQL: Realiza las operaciones necesarias
  • COMMIT: Confirma los cambios si todo fue exitoso

¿Cómo funciona?

Proceso del Procedimiento

  1. Se reciben los parámetros de entrada (usuario_id y libro_id)
  2. Se establece el manejador de errores
  3. Se inicia la transacción
  4. Se realiza el préstamo (INSERT)
  5. Se actualiza el stock (UPDATE)
  6. Si todo va bien, se hace COMMIT
  7. Si hay error, se ejecuta el ROLLBACK automáticamente

Mejores Prácticas

  • Siempre incluir manejo de errores en procedimientos con transacciones
  • Mantener las transacciones lo más cortas posible
  • Asegurarse de que todas las operaciones sean necesarias
  • Considerar el impacto en el rendimiento al usar transacciones en procedimientos almacenados
