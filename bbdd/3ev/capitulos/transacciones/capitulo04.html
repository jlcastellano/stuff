4. Ejemplo de START TRANSACTION, COMMIT y ROLLBACK


DROP DATABASE IF EXISTS test;
CREATE DATABASE test CHARACTER SET utf8mb4;
USE test;

CREATE TABLE cliente (
    id INT UNSIGNED PRIMARY KEY,
    nombre CHAR (20)
);

START TRANSACTION;
INSERT INTO cliente VALUES (1, 'Pepe');
COMMIT;

1. ¿Qué devolverá esta consulta?

SELECT * FROM cliente;

Devolverá un registro con:

  • id: 1
  • nombre: 'Pepe'

Ya que la transacción se ha confirmado con COMMIT.


SET AUTOCOMMIT=0;
INSERT INTO cliente VALUES (2, 'Maria');
INSERT INTO cliente VALUES (20, 'Juan');
DELETE FROM cliente WHERE nombre = 'Pepe';

2. ¿Qué devolverá esta consulta?

SELECT * FROM cliente;

Devolverá dos registros:

  • id: 2, nombre: 'Maria'
  • id: 20, nombre: 'Juan'

Pepe ya no aparece porque ha sido eliminado con el DELETE.

ROLLBACK;

3. ¿Qué devolverá esta consulta?

SELECT * FROM cliente;

Devolverá un registro con:

  • id: 1, nombre: 'Pepe'

Al hacer ROLLBACK, se deshacen todos los cambios de la última transacción (la inserción de Maria y Juan, y el borrado de Pepe), volviendo al estado después del primer COMMIT.

Puntos clave del ejemplo:

  • El primer COMMIT confirma la inserción de Pepe de forma permanente
  • Al desactivar AUTOCOMMIT (SET AUTOCOMMIT=0), los cambios posteriores forman parte de una transacción
  • El ROLLBACK final deshace todos los cambios de la última transacción
  • Solo se pueden deshacer los cambios que no han sido confirmados con COMMIT
