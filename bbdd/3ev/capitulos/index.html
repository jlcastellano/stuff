Índice

1. Transacciones

Las transacciones son unidades de trabajo que agrupan un conjunto de operaciones sobre la base de datos. Este módulo cubre desde su definición básica hasta conceptos avanzados como las propiedades ACID, niveles de aislamiento y gestión de la concurrencia.

2. Procedimientos Almacenados

Los procedimientos almacenados son programas que se almacenan en la base de datos y pueden ser invocados posteriormente. Se estudian conceptos como variables locales, parámetros, estructuras de control y bucles para crear procedimientos eficientes.

3. Funciones

Las funciones son rutinas que devuelven un valor específico y pueden ser utilizadas en consultas SQL. Este módulo explica cómo crear y utilizar funciones personalizadas en MySQL.

4. Cursores

Los cursores permiten recorrer y procesar resultados de consultas registro a registro. Se aprende a utilizar cursores para manipular conjuntos de datos de manera controlada.

5. Manejo de errores

El manejo de errores es crucial para crear aplicaciones robustas. Este módulo enseña cómo capturar y gestionar diferentes tipos de errores en MySQL.

6. Transacciones con manejo de errores

Combinación avanzada de transacciones y manejo de errores para garantizar la integridad de los datos incluso en situaciones de error.

7. Triggers

Los triggers son procedimientos que se ejecutan automáticamente en respuesta a ciertos eventos en las tablas. Se aprende a crear y gestionar triggers para automatizar tareas y mantener la integridad de los datos.
