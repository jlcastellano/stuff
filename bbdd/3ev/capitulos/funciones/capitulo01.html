Funciones en MySQL

Sintaxis de Creación de Funciones

CREATE
[DEFINER = { user | CURRENT_USER }]
FUNCTION sp_name ([func_parameter[,...]])
RETURNS type
[characteristic ...] routine_body

proc_parameter:
[ IN | OUT | INOUT ] param_name type

func_parameter:
param_name type

type:
Any valid MySQL data type

characteristic:
COMMENT 'string'
| LANGUAGE SQL
| [NOT] DETERMINISTIC
| { CONTAINS SQL | NO SQL | READS SQL DATA | MODIFIES SQL DATA }
| SQL SECURITY { DEFINER | INVOKER }

routine_body:
Valid SQL routine statement

Como se ha visto en el tema de procedimientos, las funciones almacenadas son similares a los procedimientos salvo que sólo devuelven un valor. Por tanto gran parte de lo que se ha expuesto en el apartado de procedimientos es válido aquí. Los permisos que hay que poseer para crear funciones se han expuesto en el apartado de procedimientos. La devolución del valor se produce utilizando la cláusula RETURN y no mediante variables OUT o INOUT.

La ventaja que presentan las funciones es que pueden ser utilizadas dentro de instrucciones SQL y por tanto aumentan considerablemente las capacidades de este lenguaje.

Cosas a tener en cuenta a la hora de utilizar funciones:

  • La cláusula RETURNS es obligatoria e indica el tipo de dato que devuelve la función.
  • No se pueden utilizar los parámetros IN, OUT, INOUT. Todos los parámetros pasados a la función se definen implícitamente del tipo IN.
  • Dentro del cuerpo de la función debe aparecer por lo menos una instrucción RETURN, que devuelve el resultado de la función al programa llamado y finaliza su ejecución. Si la ejecución de la función llega al final de la misma sin haber encontrado una instrucción RETURN, causaría un error.

Ejemplos de funciones

Ejemplo 1: Conversión de Pesetas a Euros

DELIMITER $$

CREATE FUNCTION funcion1(pesetas DECIMAL(10,2))
RETURNS DECIMAL(10,2)
BEGIN
    DECLARE euros DECIMAL(10,2);
    SET euros = pesetas/166.386;
    RETURN euros;
END $$

DELIMITER ;

La función "funcion1" devuelve en euros las pesetas que se le pasan como argumento.

Llamada a la función:

mysql> SELECT test.funcion1(10000);
+----------------------+
| test.funcion1(10000) |
+----------------------+
| 60.10                |
+----------------------+
1 row in set, 1 warning (0.00 sec)

Usando una variable:

mysql> SET @v_euros=test.funcion1(10000);
Query OK, 0 rows affected, 1 warning (0.00 sec)

mysql> SELECT @v_euros;
+----------+
| @v_euros |
+----------+
| 60.10    |
+----------+
1 row in set (0.00 sec)

Ejemplo 2: Conversión Bidireccional

DELIMITER $$

CREATE FUNCTION funcion2(tipo INT, cantidad DECIMAL(10,2))
RETURNS DECIMAL(10,2)
BEGIN
    DECLARE resultado DECIMAL(10,2);
    IF tipo = 1 THEN
        SET resultado = cantidad/166.386;
    ELSE
        SET resultado = cantidad*166.386;
    END IF;
    RETURN resultado;
END $$

DELIMITER ;

En el siguiente ejemplo la función realiza la conversión de pesetas a euros y viceversa. Si el primer argumento es un 1 entonces convertirá a euros, si es un 2 convertirá a pesetas:

Llamada a la función:

mysql> SELECT test.funcion2(2, 6);
+---------------------+
| test.funcion2(2, 6) |
+---------------------+
| 998.32             |
+---------------------+
1 row in set, 1 warning (0.00 sec)

Gestión de Funciones

Mostrar Información de Funciones

La orden SQL que permite ver la información de las funciones que existen en una BBDD es: SHOW FUNCTION STATUS.

SHOW FUNCTION STATUS WHERE Db = 'jardineria';

Borrar Funciones

La orden SQL que permite borrar un procedimiento es DROP FUNCTION.

Indicar que podemos incluir una cláusula IF EXISTS para indicar que solamente en caso de que exista, borre la función. Esto es muy útil cuando tenemos un bloque de sentencias, ya que si no ponemos el IF, si la función no existe daría un error y se dejarían de ejecutar las sentencias.

DROP FUNCTION IF EXISTS ejemplo1;

Puede encontrar más información en la documentación oficial de MySQL.
