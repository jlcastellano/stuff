6. Instrucciones condicionales

6.1 IF-THEN-ELSE

Igual en su funcionamiento que otros lenguajes de programación. Ejecuta la acción cuya expresión (condición) es cierta (de no ser cierta ninguna entonces ejecuta la acción asociada a la sentencia ELSE).

Sintaxis:

IF search_condition THEN statement_list
[ELSEIF search_condition THEN statement_list] ...
[ELSE statement_list]
END IF

Ejemplo:

DELIMITER $$
DROP PROCEDURE IF EXISTS ejemplo_if $$
CREATE PROCEDURE ejemplo_if()
BEGIN
    DECLARE numero INT DEFAULT 7;
    IF numero > 5 THEN
        SELECT 'El número es mayor que 5';
    ELSEIF numero = 5 THEN
        SELECT 'El número es igual a 5';
    ELSE
        SELECT 'El número es menor que 5';
    END IF;
END $$
DELIMITER ;

Puede encontrar más información en la documentación oficial de MySQL.

6.2 CASE

Similar a la sentencia condicional IF anterior. Todo lo que se puede expresar con la sentencia IF se puede expresar con la sentencia CASE. Esta última se suele utilizar cuando el número de expresiones o condiciones a evaluar es elevado y por tanto la lectura del código se hace más fácil y agradable.

Existen dos formas de utilizar CASE si lo que se evalúa es una expresión o una condición:

1ra forma:

CASE case_value
    WHEN when_value THEN statement_list
    [WHEN when_value THEN statement_list] ...
    [ELSE statement_list]
END CASE

Ejemplo:

DELIMITER $$
DROP PROCEDURE IF EXISTS ejemplo_case1 $$
CREATE PROCEDURE ejemplo_case1()
BEGIN
    DECLARE numero INT DEFAULT 2;
    CASE numero
        WHEN 1 THEN SELECT 'Uno';
        WHEN 2 THEN SELECT 'Dos';
        WHEN 3 THEN SELECT 'Tres';
        ELSE SELECT 'Otro número';
    END CASE;
END $$
DELIMITER ;

2da forma:

CASE
    WHEN search_condition THEN statement_list
    [WHEN search_condition THEN statement_list] ...
    [ELSE statement_list]
END CASE

Ejemplo:

DELIMITER $$
DROP PROCEDURE IF EXISTS ejemplo_case2 $$
CREATE PROCEDURE ejemplo_case2()
BEGIN
    DECLARE numero INT DEFAULT 7;
    CASE
        WHEN numero > 5 THEN SELECT 'Mayor que 5';
        WHEN numero = 5 THEN SELECT 'Igual a 5';
        ELSE SELECT 'Menor que 5';
    END CASE;
END $$
DELIMITER ;

Puede encontrar más información en la documentación oficial de MySQL.
