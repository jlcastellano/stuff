9. Bucles anidados

Consiste en utilizar comandos de repetición dentro de otros.

Ejemplo de utilización:

DELIMITER $$
DROP PROCEDURE IF EXISTS ejemplo_bucles_anidados $$
CREATE PROCEDURE ejemplo_bucles_anidados()
BEGIN
    DECLARE i INT;
    DECLARE j INT;
    SET i = 1;
    bucle1: LOOP
        IF i > 2 THEN
            LEAVE bucle1;
        END IF;
        SET j = 1;
        bucle2: LOOP
            IF j > 2 THEN
                LEAVE bucle2;
            END IF;
            SELECT CONCAT('i-j: ', i, '-', j);
            SET j = j + 1;
        END LOOP bucle2;
        SET i = i + 1;
    END LOOP bucle1;
END $$
DELIMITER ;

Al ejecutar el ejemplo anterior se visualizarán los valores i-j: 1-1, 1-2, 2-1, 2-2

Como se ha indicado en el apartado anterior de bloques de instrucciones, es importante etiquetar el comienzo y final del bucle no solo por la instrucción LEAVE o ITERATE sino por claridad en el seguimiento del código.
