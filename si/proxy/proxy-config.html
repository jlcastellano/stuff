Configuración de Squid Proxy

Guía completa de configuración y ejemplos prácticos de Squid Proxy

Instalación y Configuración Básica

Antes de comenzar, asegúrate de tener privilegios de administrador y actualizar tu sistema.

Instalación

  1. Actualizar repositorios: 
    sudo apt update
  2. Instalar Squid: 
    sudo apt install squid
  3. Verificar instalación: 
    squid -v

Configuración Básica

El archivo principal de configuración se encuentra en /etc/squid/squid.conf

# Configuración del puerto de escucha
http_port 3128

# ACL para red local
acl localnet src 192.168.1.0/24

# Permitir acceso a la red local
http_access allow localnet

# Denegar el resto
http_access deny all

# Configuración básica de caché
cache_dir ufs /var/spool/squid 1000 16 256
maximum_object_size 100 MB
cache_mem 256 MB

Control de Acceso

Restricción por Horario

# Definir horario laboral
acl horario_laboral time M T W H F 08:00-17:00

# Permitir acceso solo en horario laboral
http_access allow localnet horario_laboral
http_access deny all

Restricción por Dominio

# Lista de dominios bloqueados
acl sitios_bloqueados dstdomain "/etc/squid/sitios_bloqueados.txt"

# Denegar acceso a sitios bloqueados
http_access deny sitios_bloqueados

Autenticación de Usuarios

Asegúrate de instalar el paquete apache2-utils para usar htpasswd.

# Configuración de autenticación básica
auth_param basic program /usr/lib/squid/basic_ncsa_auth /etc/squid/passwd
auth_param basic children 5
auth_param basic realm Proxy Authentication Required
auth_param basic credentialsttl 2 hours

# ACL para usuarios autenticados
acl authenticated proxy_auth REQUIRED

# Permitir acceso solo a usuarios autenticados
http_access allow authenticated
http_access deny all

Crear usuarios:

sudo htpasswd -c /etc/squid/passwd usuario1
sudo htpasswd /etc/squid/passwd usuario2

Configuración de Caché

# Configuración de directorio de caché
cache_dir ufs /var/spool/squid 10000 16 256

# Tamaño máximo de objetos en caché
maximum_object_size 50 MB
minimum_object_size 0 KB

# Memoria para caché
cache_mem 512 MB

# Políticas de reemplazo
cache_replacement_policy lru
memory_replacement_policy lru

# Patrones de refresco
refresh_pattern ^ftp:           1440    20%     10080
refresh_pattern ^gopher:        1440    0%      1440
refresh_pattern -i (/cgi-bin/|\?) 0    0%      0
refresh_pattern .               0       20%     4320

Configuración de Logs

# Configuración de logs de acceso
access_log /var/log/squid/access.log squid

# Formato personalizado de logs
logformat combinado %>a %ui %un [%tl] "%rm %ru HTTP/%rv" %>Hs %h" "%{User-Agent}>h"

# Configuración de cache.log
cache_log /var/log/squid/cache.log

# Log de almacenamiento
cache_store_log /var/log/squid/store.log

Optimización de Rendimiento

# Número de procesos hijos
workers 4

# Configuración de memoria
cache_mem 1024 MB
maximum_object_size_in_memory 512 KB

# Optimización de descriptores de archivo
max_filedesc 8192

# Optimización de sockets
tcp_recv_bufsize 65535 bytes

SSL/HTTPS

La interceptación HTTPS requiere configuración adicional de certificados y consideraciones de privacidad.

# Configuración de puerto SSL
https_port 3129 cert=/etc/squid/ssl/squid.crt key=/etc/squid/ssl/squid.key

# ACL para HTTPS
acl SSL_ports port 443
acl CONNECT method CONNECT

# Permitir CONNECT solo a puertos SSL
http_access deny CONNECT !SSL_ports
