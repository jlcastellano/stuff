Proxy: Definición y Usos

¿Qué es un Proxy?

Un servidor proxy es un sistema o aplicación que actúa como intermediario entre los usuarios y los recursos que solicitan en Internet. Funciona como una capa de abstracción y control que puede modificar, redirigir o filtrar las solicitudes según reglas predefinidas.

Características Fundamentales

  • Intermediación de conexiones
  • Procesamiento en la capa de aplicación (Capa 7 del modelo OSI)
  • Capacidad de modificar y filtrar contenido
  • Almacenamiento en caché
  • Control de acceso y autenticación

Funcionamiento Técnico

[Cliente] ←→ [Servidor Proxy] ←→ [Internet]

Proceso de una Solicitud

  1. El cliente envía una solicitud al servidor proxy
  2. El proxy verifica las políticas de acceso y reglas de filtrado
  3. Si está permitido, el proxy reenvía la solicitud al servidor destino
  4. El servidor destino responde al proxy
  5. El proxy puede almacenar la respuesta en caché
  6. El proxy reenvía la respuesta al cliente
