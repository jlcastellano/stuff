Servidor Proxy

Configuración y gestión de servidores proxy para optimización y seguridad de red

¿Qué es un Servidor Proxy?

Un servidor proxy actúa como intermediario entre los usuarios de una red local y la Internet, permitiendo:

  • Control de acceso a contenidos
  • Almacenamiento en caché
  • Anonimización de conexiones
  • Balanceo de carga

Instalación de Squid Proxy

Pasos de Instalación en Ubuntu/Debian

  1. Actualizar repositorios:
    sudo apt update
  2. Instalar Squid:
    sudo apt install squid
  3. Verificar estado:
    sudo systemctl status squid
                # Configuración básica de Squid (/etc/squid/squid.conf)
                
http_port 3128

# ACL para red local
acl localnet src 192.168.1.0/24

# ACL para sitios permitidos
acl whitelist dstdomain "/etc/squid/whitelist.txt"

# ACL para sitios prohibidos
acl blacklist dstdomain "/etc/squid/blacklist.txt"

# Reglas de acceso
http_access deny blacklist
http_access allow localnet whitelist
http_access deny all

Configuración de Caché

# Configuración de caché en Squid
cache_dir ufs /var/spool/squid 10000 16 256
maximum_object_size 100 MB
cache_mem 512 MB

# Políticas de caché
refresh_pattern ^ftp:           1440    20%     10080
refresh_pattern ^gopher:        1440    0%      1440
refresh_pattern -i (/cgi-bin/|\?) 0     0%      0
refresh_pattern .               0       20%     4320

Nota sobre Caché:

La configuración de caché debe ajustarse según los recursos del servidor y el tráfico esperado.

Autenticación de Usuarios

# Configuración de autenticación básica auth_param basic program /usr/lib/squid/basic_ncsa_auth /etc/squid/passwd auth_param basic children 5 auth_param basic realm Proxy Authentication Required auth_param basic credentialsttl 2 hours # ACL para usuarios autenticados acl authenticated proxy_auth REQUIRED # Regla de acceso para usuarios autenticados http_access allow authenticated

Crear usuario para autenticación:

sudo htpasswd -c /etc/squid/passwd usuario1

Configuración de Logs

# Configuración de logs
access_log /var/log/squid/access.log squid
cache_log /var/log/squid/cache.log
cache_store_log /var/log/squid/store.log

# Formato personalizado de logs
logformat combined %>a %[ui %[un [%tl] "%rm %ru HTTP/%rv" %>Hs %h" "%{User-Agent}>h"

Configuración de Cliente

Windows:

  1. Abrir Configuración de Red
  2. Configuración de Proxy Manual:
    • Dirección: IP_DEL_SERVIDOR
    • Puerto: 3128

Linux (Terminal):

export http_proxy="http://IP_DEL_SERVIDOR:3128"
export https_proxy="http://IP_DEL_SERVIDOR:3128"

Monitorización y Mantenimiento

Comandos útiles

# Verificar sintaxis de configuración squid -k parse # Recargar configuración squid -k reconfigure # Rotar logs squid -k rotate # Limpiar caché squid -k shutdown rm -rf /var/spool/squid/* squid -z service squid start

Recomendaciones de Seguridad:

  • Mantener Squid actualizado
  • Revisar logs regularmente
  • Implementar límites de ancho de banda
  • Configurar correctamente los permisos de archivos
