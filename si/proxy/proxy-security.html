Seguridad en Squid Proxy

Guía completa de configuración de seguridad y mejores prácticas para Squid Proxy

Autenticación Segura

La autenticación es la primera línea de defensa en tu proxy. Implementa autenticación robusta para controlar el acceso.

Autenticación LDAP

# Configuración de autenticación LDAP
auth_param basic program /usr/lib/squid/basic_ldap_auth -b "dc=ejemplo,dc=com" -f "uid=%s" ldap.ejemplo.com
auth_param basic children 5
auth_param basic realm Proxy Authentication Required
auth_param basic credentialsttl 2 hours

# ACL para usuarios autenticados
acl authenticated proxy_auth REQUIRED
http_access allow authenticated

Autenticación con Digest

# Configuración de autenticación Digest
auth_param digest program /usr/lib/squid/digest_file_auth /etc/squid/digest_passwords
auth_param digest children 5
auth_param digest realm Proxy Authentication
auth_param digest nonce_garbage_interval 5 minutes
auth_param digest nonce_max_duration 30 minutes
auth_param digest nonce_max_count 50

Control de Acceso Avanzado

Restricciones por IP y Red

# ACLs para control de acceso por IP
acl red_confiable src 192.168.1.0/24
acl red_admin src 192.168.2.0/24
acl servidores_internos dst 10.0.0.0/8

# Reglas de acceso
http_access allow red_admin
http_access allow red_confiable servidores_internos
http_access deny all

Restricciones por Protocolo y Puerto

# Definición de puertos seguros
acl SSL_ports port 443
acl Safe_ports port 80          # http
acl Safe_ports port 443         # https
acl Safe_ports port 1025-65535  # puertos no privilegiados
acl CONNECT method CONNECT

# Reglas de seguridad para puertos
http_access deny !Safe_ports
http_access deny CONNECT !SSL_ports

Filtrado de Contenido

Bloqueo de Sitios por Dominio

# Bloqueo de sitios específicos
acl sitios_bloqueados dstdomain "/etc/squid/sitios_bloqueados.txt"
acl palabras_clave url_regex -i "/etc/squid/palabras_clave.txt"

# Reglas de bloqueo
http_access deny sitios_bloqueados
http_access deny palabras_clave

Filtrado MIME

# Bloqueo de tipos MIME específicos
acl tipos_bloqueados rep_mime_type ^application/executable$
acl extensiones_bloqueadas urlpath_regex \.exe$ \.bat$ \.cmd$

# Reglas de bloqueo
http_reply_access deny tipos_bloqueados
http_access deny extensiones_bloqueadas

Configuración SSL/HTTPS

La interceptación SSL debe implementarse con cuidado y considerando las implicaciones de privacidad.

# Configuración SSL Bump
http_port 3128 ssl-bump \
    cert=/etc/squid/ssl_cert/squid.pem \
    generate-host-certificates=on \
    dynamic_cert_mem_cache_size=4MB

# ACLs para SSL
acl step1 at_step SslBump1
acl step2 at_step SslBump2
acl step3 at_step SslBump3

# Reglas SSL Bump
ssl_bump peek step1
ssl_bump bump step2
ssl_bump splice step3

Protección contra Ataques

Límites de Conexión

# Límites de conexión por cliente
acl clientes_excesivos maxconn 10
http_access deny clientes_excesivos

# Configuración de delay pools
delay_pools 2
delay_class 1 1
delay_parameters 1 16000/16000
delay_access 1 allow all

Protección contra DOS

# Configuración de cuotas
acl magic_words url_regex -i \.mp3$ \.exe$ \.zip$
delay_pools 1
delay_class 1 2
delay_access 1 allow magic_words
delay_parameters 1 -1/-1 64000/128000

Monitoreo y Logs

Configuración de Logs Detallados

# Formato de log personalizado
logformat squid_security %ts.%03tu %6tr %>a %Ss/%03>Hs %

Auditoría de Seguridad

# Configuración de debug para auditoría
debug_options ALL,1 33,2 28,9
cache_log /var/log/squid/security_audit.log

# Rotación de logs
logfile_rotate 7
authenticate_ttl 1 hour
negative_ttl 1 minute
