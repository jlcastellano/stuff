Ejercicio 1: Configuración Básica

Configura un servidor Squid proxy básico que:

  • Escuche en el puerto 3128
  • Permita acceso desde la red local 192.168.1.0/24
  • Deniegue todo otro acceso
# Configuración básica de Squid
http_port 3128

# Definir ACL para red local
acl localnet src 192.168.1.0/24

# Reglas de acceso
http_access allow localnet
http_access deny all

# Configuración básica de caché
cache_dir ufs /var/spool/squid 100 16 256

Ejercicio 2: Autenticación Simple

Implementa autenticación básica con los siguientes requisitos:

  • Usar autenticación básica con archivo de contraseñas
  • Crear dos usuarios: admin y usuario1
  • Las credenciales deben expirar después de 2 horas
# Crear archivo de contraseñas
# sudo htpasswd -c /etc/squid/passwd admin
# sudo htpasswd /etc/squid/passwd usuario1

# Configuración de autenticación
auth_param basic program /usr/lib/squid/basic_ncsa_auth /etc/squid/passwd
auth_param basic children 5
auth_param basic realm Proxy Authentication Required
auth_param basic credentialsttl 2 hours

# ACL para usuarios autenticados
acl authenticated proxy_auth REQUIRED

# Reglas de acceso
http_access allow authenticated
http_access deny all

Ejercicio 3: Control de Acceso por Horario

Configura un proxy que:

  • Permita acceso solo en horario laboral (Lunes a Viernes, 8:00-17:00)
  • Bloquee sitios específicos en todo momento
  • Permita acceso a ciertos sitios sin restricción horaria
# Definir ACLs de tiempo y sitios
acl horario_laboral time M T W H F 8:00-17:00
acl sitios_bloqueados dstdomain "/etc/squid/sitios_bloqueados.txt"
acl sitios_permitidos dstdomain "/etc/squid/sitios_permitidos.txt"

# Reglas de acceso
http_access allow sitios_permitidos
http_access deny sitios_bloqueados
http_access allow localnet horario_laboral
http_access deny all

Ejercicio 4: Configuración de Caché

Implementa una configuración de caché que:

  • Use 2GB de espacio en disco
  • Limite el tamaño máximo de objetos a 50MB
  • Configure patrones de refresco específicos para diferentes tipos de contenido
# Configuración de caché
cache_dir ufs /var/spool/squid 2048 16 256
maximum_object_size 50 MB
cache_mem 512 MB

# Patrones de refresco
refresh_pattern ^ftp:           1440    20%     10080
refresh_pattern -i \.(gif|png|jpg|jpeg|ico)$ 1440 50% 2880
refresh_pattern -i \.(css|js)$  1440    50%     2880
refresh_pattern .               0       20%     4320

Ejercicio 5: SSL Bump y HTTPS

Configura SSL Bump para:

  • Interceptar tráfico HTTPS
  • Generar certificados dinámicamente
  • Excluir sitios bancarios y de salud
# Configuración SSL
http_port 3128 ssl-bump \
    cert=/etc/squid/ssl_cert/squid.pem \
    generate-host-certificates=on \
    dynamic_cert_mem_cache_size=4MB

# ACLs para SSL
acl step1 at_step SslBump1
acl step2 at_step SslBump2
acl step3 at_step SslBump3
acl sitios_nobump ssl::server_name .banco.com .salud.org

# Reglas SSL Bump
ssl_bump splice sitios_nobump
ssl_bump peek step1
ssl_bump bump step2
ssl_bump splice step3

Ejercicio 6: Balanceo de Carga y Alta Disponibilidad

Configura un sistema de proxy con:

  • Balanceo de carga entre dos servidores Squid
  • Configuración de caché peer
  • Monitoreo de salud de los servidores
# Configuración de cache_peer
cache_peer 192.168.1.10 parent 3128 0 no-query
cache_peer 192.168.1.11 parent 3128 0 no-query round-robin

# ICP queries
icp_port 3130
icp_access allow localnet

# Configuración de cache_peer_access
cache_peer_access 192.168.1.10 allow all
cache_peer_access 192.168.1.11 allow all

# Monitoreo de salud
cache_peer_domain 192.168.1.10 *
cache_peer_domain 192.168.1.11 *

# Logging específico
cache_log /var/log/squid/cache.log
cache_store_log /var/log/squid/store.log
logformat combined %>a %ui %un [%tl] "%rm %ru HTTP/%rv" %>Hs %h" "%{User-Agent}>h"
