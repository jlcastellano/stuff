UFW (Uncomplicated Firewall)

🎯 Objetivos de Aprendizaje

  • Comprender qué es UFW y sus ventajas
  • Aprender a instalar y configurar UFW
  • Dominar la gestión de reglas de firewall
  • Implementar configuraciones de seguridad efectivas

1. Introducción a UFW

UFW (Uncomplicated Firewall) es una interfaz simplificada para IPTables que facilita la configuración del firewall en sistemas Ubuntu y derivados. Está diseñado para ser fácil de usar mientras mantiene la potencia de IPTables.

1.1 Ventajas de UFW

  • Sintaxis simplificada
  • Configuración rápida
  • Integración con sistemas Ubuntu
  • Soporte para IPv6
  • Interfaz de línea de comandos intuitiva

2. Instalación y Configuración Inicial

2.1 Instalación

# Instalar UFW
sudo apt update
sudo apt install ufw

# Verificar instalación
sudo ufw version

2.2 Configuración Básica

# Verificar estado actual
sudo ufw status verbose

# Habilitar IPv6 (editar /etc/default/ufw)
sudo nano /etc/default/ufw
IPV6=yes

# Restablecer configuración
sudo ufw reset

3. Gestión de Reglas Básicas

Comando Descripción Ejemplo
allow Permitir tráfico sudo ufw allow 80
deny Denegar tráfico sudo ufw deny 23
reject Rechazar tráfico con respuesta sudo ufw reject 80
delete Eliminar regla sudo ufw delete allow 80

3.1 Reglas por Servicio

# Permitir servicios comunes
sudo ufw allow ssh
sudo ufw allow http
sudo ufw allow https
sudo ufw allow ftp

# Permitir servicios por número de puerto
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

3.2 Reglas por Dirección IP

# Permitir acceso desde IP específica
sudo ufw allow from 192.168.1.100

# Permitir acceso a puerto específico desde IP
sudo ufw allow from 192.168.1.100 to any port 22

# Permitir rango de IPs
sudo ufw allow from 192.168.1.0/24

4. Configuraciones Avanzadas

4.1 Rangos de Puertos

# Permitir rango de puertos
sudo ufw allow 6000:6007/tcp
sudo ufw allow 6000:6007/udp

# Permitir múltiples puertos
sudo ufw allow 80,443/tcp

4.2 Reglas con Interfaces

# Permitir tráfico en interfaz específica
sudo ufw allow in on eth0 to any port 80
sudo ufw allow out on eth0 from any to any port 80

# Denegar tráfico en interfaz
sudo ufw deny in on eth1

4.3 Configuración de Logging

# Habilitar logging
sudo ufw logging on

# Configurar nivel de logging
sudo ufw logging low|medium|high

# Ver logs
sudo tail -f /var/log/ufw.log

5. Perfiles de Aplicación

# Listar aplicaciones disponibles
sudo ufw app list

# Mostrar información de perfil
sudo ufw app info 'Apache'

# Permitir perfil completo
sudo ufw allow 'Apache Full'

💡 Perfiles Comunes

  • Apache Full: Puertos 80 y 443
  • Apache: Solo puerto 80
  • Apache Secure: Solo puerto 443
  • OpenSSH: Puerto 22

6. Configuraciones de Seguridad Recomendadas

6.1 Configuración Básica de Servidor

# Configuración inicial segura
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow ssh
sudo ufw allow http
sudo ufw allow https
sudo ufw enable

6.2 Configuración para Servidor Web

# Configuración Apache/Nginx
sudo ufw allow 'Apache Full'
sudo ufw allow from 192.168.1.0/24 to any port 22
sudo ufw limit ssh

6.3 Rate Limiting

# Limitar intentos de conexión SSH
sudo ufw limit ssh

# Limitar conexiones a puerto específico
sudo ufw limit 3306/tcp

7. Administración y Mantenimiento

7.1 Gestión de Estado

# Activar/Desactivar UFW
sudo ufw enable
sudo ufw disable

# Recargar reglas
sudo ufw reload

# Restablecer configuración
sudo ufw reset

7.2 Backup y Restauración

# Backup de reglas
sudo cp /etc/ufw/user.rules /etc/ufw/user.rules.backup
sudo cp /etc/ufw/before.rules /etc/ufw/before.rules.backup

# Restaurar reglas
sudo cp /etc/ufw/user.rules.backup /etc/ufw/user.rules
sudo ufw reload

8. Troubleshooting

Comandos de Diagnóstico

# Ver estado detallado
sudo ufw status verbose

# Ver reglas numeradas
sudo ufw status numbered

# Ver reglas raw
sudo ufw show raw

# Verificar logs
sudo tail -f /var/log/ufw.log

⚠️ Solución de Problemas Comunes

  • Si pierdes acceso SSH: Accede físicamente al servidor y deshabilita UFW
  • Conflictos con Docker: Ajusta las reglas de forward
  • Problemas con servicios: Verifica los logs y las reglas aplicadas
  • Rendimiento: Minimiza el número de reglas

9. Ejemplos de Scripts de Automatización

#!/bin/bash
# Script de configuración básica de UFW

# Resetear configuración
sudo ufw reset

# Configurar políticas por defecto
sudo ufw default deny incoming
sudo ufw default allow outgoing

# Permitir servicios básicos
sudo ufw allow ssh
sudo ufw allow http
sudo ufw allow https

# Configurar límites
sudo ufw limit ssh

# Permitir red local
sudo ufw allow from 192.168.1.0/24

# Activar UFW
sudo ufw --force enable

# Verificar estado
sudo ufw status verbose
