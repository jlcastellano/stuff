IPTables en Ubuntu

🎯 Objetivos de Aprendizaje

  • Comprender la arquitectura de IPTables
  • Aprender a gestionar reglas de firewall
  • Implementar políticas de seguridad efectivas
  • Proteger servicios y servidores

1. Fundamentos de IPTables

1.1 Tablas Principales

  • filter: Tabla por defecto, usada para filtrado de paquetes
  • nat: Para traducción de direcciones de red
  • mangle: Para modificación especializada de paquetes
  • raw: Para configuraciones de exención de seguimiento de conexiones

1.2 Cadenas Fundamentales

  • INPUT: Paquetes destinados al sistema local
  • OUTPUT: Paquetes generados localmente
  • FORWARD: Paquetes enrutados a través del sistema
  • PREROUTING: Alteración de paquetes antes del enrutamiento
  • POSTROUTING: Alteración de paquetes después del enrutamiento

2. Sintaxis Básica de IPTables

Parámetro Descripción Ejemplo
-A Añadir regla al final de la cadena iptables -A INPUT
-I Insertar regla en posición específica iptables -I INPUT 1
-D Eliminar regla iptables -D INPUT 1
-F Limpiar todas las reglas iptables -F

3. Gestión de Reglas

3.1 Visualización de Reglas

# Mostrar todas las reglas con números de línea
sudo iptables -L -v -n --line-numbers

# Mostrar reglas de una cadena específica
sudo iptables -L INPUT -v -n --line-numbers

# Mostrar reglas en formato exacto
sudo iptables-save

3.2 Políticas por Defecto

# Configurar políticas predeterminadas
sudo iptables -P INPUT DROP
sudo iptables -P OUTPUT ACCEPT
sudo iptables -P FORWARD DROP

# Verificar políticas actuales
sudo iptables -L | grep policy

4. Configuraciones Avanzadas

4.1 Control de Estado de Conexiones

# Permitir conexiones establecidas y relacionadas
sudo iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# Permitir nuevas conexiones a servicios específicos
sudo iptables -A INPUT -p tcp --dport 80 -m state --state NEW -j ACCEPT

4.2 Limitación de Conexiones

# Limitar conexiones SSH a 3 por minuto
sudo iptables -A INPUT -p tcp --dport 22 -m state --state NEW \
    -m recent --set --name SSH
sudo iptables -A INPUT -p tcp --dport 22 -m state --state NEW \
    -m recent --update --seconds 60 --hitcount 3 --rttl --name SSH -j DROP

4.3 Protección contra Ataques Comunes

# Protección contra SYN flood
sudo iptables -A INPUT -p tcp --syn -m limit --limit 1/s -j ACCEPT

# Protección contra port scanning
sudo iptables -A INPUT -p tcp --tcp-flags ALL NONE -j DROP
sudo iptables -A INPUT -p tcp --tcp-flags ALL ALL -j DROP

# Protección contra ping of death
sudo iptables -A INPUT -p icmp --icmp-type echo-request \
    -m limit --limit 1/s -j ACCEPT

5. Persistencia de Reglas

# Instalar herramienta de persistencia
sudo apt-get install iptables-persistent

# Guardar reglas actuales
sudo netfilter-persistent save

# Recargar reglas
sudo netfilter-persistent reload

# Backup manual de reglas
sudo iptables-save > /root/iptables_backup

6. Ejemplos de Configuraciones Comunes

6.1 Configuración Básica de Servidor Web

# Limpiar reglas existentes
sudo iptables -F
sudo iptables -X
sudo iptables -Z

# Establecer políticas por defecto
sudo iptables -P INPUT DROP
sudo iptables -P OUTPUT ACCEPT
sudo iptables -P FORWARD DROP

# Permitir localhost
sudo iptables -A INPUT -i lo -j ACCEPT

# Permitir conexiones establecidas
sudo iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# Permitir SSH
sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT

# Permitir HTTP/HTTPS
sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT

6.2 Configuración para Base de Datos

# Permitir MySQL solo desde red local
sudo iptables -A INPUT -p tcp -s 192.168.1.0/24 --dport 3306 -j ACCEPT

# Permitir PostgreSQL con limitación de conexiones
sudo iptables -A INPUT -p tcp --dport 5432 -m state --state NEW \
    -m recent --set --name PSQL
sudo iptables -A INPUT -p tcp --dport 5432 -m state --state NEW \
    -m recent --update --seconds 60 --hitcount 10 --rttl --name PSQL -j DROP

⚠️ Precauciones Importantes

  • Siempre mantener una sesión de respaldo al configurar reglas
  • Probar las reglas en un entorno de desarrollo primero
  • Documentar todos los cambios realizados
  • Realizar copias de seguridad antes de modificaciones importantes

7. Troubleshooting

Comandos Útiles para Diagnóstico

# Ver contador de paquetes por regla
sudo iptables -L -v

# Ver reglas que afectan a un puerto específico
sudo iptables -L INPUT -v -n | grep dport 80

# Seguimiento de conexiones activas
sudo cat /proc/net/nf_conntrack

8. Scripts de Automatización

#!/bin/bash
# Script básico de configuración de firewall

# Limpiar reglas existentes
iptables -F
iptables -X
iptables -Z

# Políticas por defecto
iptables -P INPUT DROP
iptables -P OUTPUT ACCEPT
iptables -P FORWARD DROP

# Reglas básicas
iptables -A INPUT -i lo -j ACCEPT
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT
iptables -A INPUT -p tcp --dport 22 -j ACCEPT

iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# Guardar configuración
netfilter-persistent save
