Capítulo 4: Principios de Protección de Datos

Los principios de protección de datos constituyen los pilares fundamentales sobre los que se asienta toda la normativa. Su cumplimiento es obligatorio y debe poder demostrarse en todo momento (principio de responsabilidad proactiva).

4.1 Licitud, lealtad y transparencia

Licitud

Todo tratamiento debe basarse en una base jurídica válida:

  • Consentimiento del interesado
  • Ejecución de un contrato
  • Obligación legal
  • Intereses vitales
  • Interés público
  • Interés legítimo

Ejemplo práctico:

Una empresa que necesita los datos de sus empleados para la gestión de nóminas tiene como base jurídica la ejecución del contrato laboral.

Lealtad

Los datos deben tratarse de manera leal y lícita, sin utilizar medios fraudulentos o engañosos.

✓ Prácticas leales

  • Informar claramente sobre la finalidad
  • Usar datos solo para los fines declarados
  • Permitir el ejercicio de derechos

✗ Prácticas desleales

  • Ocultar finalidades del tratamiento
  • Dificultar el ejercicio de derechos
  • Usar datos para fines no declarados

Transparencia

La información debe ser:

  • Concisa y de fácil acceso
  • Usando lenguaje claro y sencillo
  • Gratuita
  • Facilitada por escrito o por medios electrónicos

4.2 Limitación de la finalidad

Finalidades determinadas

Los datos deben recogerse con fines:

  • Determinados
  • Explícitos
  • Legítimos

No se permite el tratamiento posterior de manera incompatible con dichos fines.

Caso práctico:

Una empresa recopila emails para enviar newsletters. No puede usar esos emails para vender la base de datos a terceros sin consentimiento específico.

4.3 Minimización de datos

Datos adecuados

Los datos deben ser:

  • Adecuados
  • Pertinentes
  • Limitados a lo necesario

✓ Buenas prácticas

  • Recoger solo datos necesarios
  • Revisar periódicamente los datos
  • Eliminar datos superfluos

✗ Malas prácticas

  • Recoger datos "por si acaso"
  • Mantener datos innecesarios
  • Solicitar datos excesivos

4.4 Exactitud

Datos exactos

Los datos deben ser:

  • Exactos
  • Actualizados

Medidas necesarias:

  • Procedimientos de actualización
  • Sistemas de verificación
  • Procesos de rectificación
  • Supresión de datos inexactos

Ejercicio de evaluación:

Para cada tratamiento de datos en tu organización:

  1. Identifica la base legal que lo legitima
  2. Verifica que los datos son los mínimos necesarios
  3. Comprueba los procedimientos de actualización
  4. Documenta las medidas implementadas
